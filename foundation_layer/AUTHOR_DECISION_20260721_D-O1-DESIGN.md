УТВЕРЖДЁННЫЙ ДИЗАЙН-СКЕЛЕТ (что закрыто)
============================================================
1. МЕСТО: отдельный per-occurrence слой НАД гардом/картой. `_SCOPE_RISK` и гейт стр.741
   НЕ РЕДАКТИРУЮТСЯ (CI-пин файла). НЕ внутри гарда.
2. ВХОД: occurrence-запись КАЖДОГО вхождения (включая загейтованные в NONE) — параллельно
   relation-гейту, ДО финального интегратора. Детекций НЕ создаёт, только пересчитывает уровень.
   [Крест: пост-ACTION ремэпперу «нечего ремэпить», т.к. FREE_TEXT-гейт может не эмитить
   кандидата — Kimi+GPT сошлись.]
3. ФОРМА: спарс exact-match реестр. Ключ = (sign_id, context, occurrence_role [, relation/seq]).
   БЕЗ wildcard, БЕЗ класс-дефолта. Строка — только с provenance-ID (reconcile + author decision).
4. ПРЕДИКАТ (occurrence_role) — В КАРТОЧКЕ: ZWJ=PER_OCCURRENCE_BOUNDARY, BOM=OBSERVATION_LEVEL.
5. COMBINE: final = max(base, policy). Absence=identity. ТОЛЬКО ЭСКАЛАЦИЯ.
6. WITNESS: ЧИСТО=NONE→pass · ВОЗМОЖНАЯ=MEDIUM→queue · РЕАЛЬНАЯ=HIGH→hold. CRITICAL/escalate — линт-запрет.
7. КЛЮЧ ПО ИЗМЕРЕННОМУ КОНТЕКСТУ (не идеальному): «ведущий-перед-доменом» измерен MEDIUM =
   детектор не увидел HOST (BOM-префикс сломал разбор). Таблица «reconcile-строка → контекст» —
   часть плана. [Съезд контекста от BOM-префикса — сигнал для B5/инкремента-2 гарда, не O1.]
8. КОНФЛИКТ-ГЕЙТ: одинаковые условия + разный target → NO ACTIVATION → author decision.
9. АУДИТ: отчёт несёт {base_level, final_level, rule_id, provenance}. Позиции/спаны не трогаются.
10. PER-OCCURRENCE: final = max(по вхождениям); отчёт хранит, какое вхождение эскалировало
    (закрывает мульти-знак/мульти-вхождение — GPT).
11. ACCEPTANCE (обязателен ПЕРЕД мержем): (i) ZWSP 21/21 + mutation 5/5 + oracle с НЕИЗМЕННЫМИ
    ожиданиями; (ii) DELTA-CENSUS (меняются РОВНО авторизованные ячейки, всё прочее = FAIL);
    (iii) FP-бюджет на benign; (iv) MUT-O1-01..08; (v) FULL-DIFFERENTIAL (21 кейс ZWSP по
    {context,risk,action,verdict,relation,witness,positions,rationale}; дельта = только O1_TRACE).
12. ЭТАПНОСТЬ: v1 = только предъявленные reconcile-строки. Механизм класс-способен, данные растут
    с доказательствами. Остальные 135–136: presence/witness ДА, severity-override НЕТ.

ЧЕСТНО: «21/21 зелёные = гарантия для ВЕРИФИЦИРОВАННОЙ батареи, НЕ мат-доказательство для любой
  строки» (GPT). Сходимость 6/6 + 2 независимые красные команды = проверено на излом, не абсолют.
