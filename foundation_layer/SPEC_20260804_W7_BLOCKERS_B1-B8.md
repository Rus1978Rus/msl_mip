## §0 ЗАМЕР ПОД СПЕКУ (живое ядро, 2026-08-04 — новые факты после свода)
- `http://paypal.com@evil.com` → **hold** (сегодня): AT-карточка уже эскалирует двойной-домен-вокруг-@
  (userinfo-трюк). `http://pаypal.com@evil.com` (кирилл. а) → hold той же механикой; голый
  `pаypal.com@evil.com` → queue. **Дыра userinfo из свода МЕНЬШЕ заявленной** — покрыта AT-путём.
- `α-user@lab.org` → pass (local-part не домен-форма) — совпадает с требуемой ячейкой B5.
- `_looks_like_domain('pаypal.com')` = **True**: распознавание домен-формы уже юникодное (isalnum) —
  ось W7 едет на существующем субстрате, отдельный host-парсер НЕ нужен.
- stdlib punycode (RFC 3492, версия-стабильный): `xn--80ak6aa92e`→`аррӏе`, `xn--pypal-4ve`→`pаypal`.
- `unicodedata.unidata_version == '16.0.0'` (текущая сборка).

## B1 — СПЕКА извлечения host-токена [ЗАКРЫТ]
**S1.1** Host-кандидат оси W7 = любой максимальный токен текста, чья форма проходит существующий
  `_looks_like_domain` (после канона разделителей + ACE-декода по B2). **Позиционно-независимо**
  (проза / URL / userinfo): witness-рамка судит то, что видит глаз, а не навигационную семантику браузера.
**S1.2** Userinfo: НЕ строить новую механику. AT-карточка уже эскалирует `A@B` (замер §0). Ось W7
  дополнительно анализирует ОБЕ стороны `@` как независимые домен-формы (по S1.1) — confusable в
  userinfo-приманке (`pаypal.com@evil.com`) получает confusable-сигнал поверх AT-сигнала (raise-only, D8).
**S1.3** Email local-part: не домен-форма (нет точки+TLD) → ось молчит. Ячейка B5: `α-user@lab.org` → pass.
**S1.4** Видимый-текст vs href: текстовое ядро НЕ видит HTML-структуру → вне области W7; именованный
  остаток R7 (реестр B8), принадлежит фронту режимов B/C (файлы/потоки).

## B2 — IDNA/punycode-декод ДО детекта [ЗАКРЫТ]
**S2.1** Label с ACE-префиксом `xn--` декодируется stdlib punycode (RFC 3492 — стабилен, версия-дрейфа
  нет, замер §0); декодированная форма подаётся в confusable-ось; сырой вход сохраняется (D8).
**S2.2** Ошибка декода (битый ACE) → fail-visible: witness `UNVERIFIABLE_ACE` (без крэша, без тихого
  пропуска). Паритет с канон-политикой card-load structured failure.
**S2.3** УТОЧНЕНИЕ пина UTS#46 (против свода, по r>g): first-cut пинит НЕ полную IdnaMappingTable, а
  (а) punycode RFC 3492 (стандарт без версий таблиц) + (б) микро-таблицу разделителей `。．｡→.`
  (уже в коде `_DOMAIN_DOT_CANON`, sequence_engine.py:540), документированную как производную от
  UTS#46 16.0.0. Полная IdnaMappingTable = именованный остаток R8 (реестр B8). BASIS: полная таблица —
  масса g без измеренного r; разделители и ACE — измеренные векторы.

**S3.3** Production-поднабор (полная UTS#39 МИНУС 4 отложенных D6) — генерируется из снапшота скриптом,

## B4 — Порядок пайплайна: детект → событие → канонизация [ЗАКРЫТ]
**S4.1** Разделитель-двойник (`。．｡`) в домен-форме: событие `SEPARATOR_LOOKALIKE` (семья, позиции,
  сырой вход) порождается ДО использования канон-формы для распознавания. `_canon_domain_seps` остаётся
  recognition-only; сигнал даёт новая separator-ось (D4). Тихий ремонт входа запрещён.
**S4.2** Переподпись §1 пакета (выполнена в своде, фиксируется спекой): `paypal．com` → pass = факт;
  ярлык «spoof» снят; вектор = parser-differential (расхождение парсеров границ label), уровень queue
  через separator-ось, hold — только при collision с protected-доменом (ярус 2).

## B5 — Батарея на frozen baseline [ЗАКРЫТ]
**S5.1** Frozen baseline = гейт-набор на коммите c7983bb (26 гейтов) — ожидания побайтово заморожены;
  движение baseline вместе с детектором запрещено (ловушка ре-базлайна REDTEAM). «Не-confusable вход» =
  ПЕРЕЧИСЛЕНИЕ корпуса, не свойство «нет знаков из таблицы».
**S5.2** Новые ячейки — аддитивный гейт `gate_w7_confusable.py` (код-фаза), обязательный минимум:
  ПОЗИТИВЫ (→queue, ярус 1): `pаypal.com`(U+0430) · `gоogle.com`(U+043E) · `gοogle.com`(U+03BF) ·
  `gօogle.com`(U+0585) · `Ⅽoinbase.com`(U+216D) · `PаYPAL.com`(регистр) · `xn--pypal-4ve.com`
  (после ACE-декода) · `pаypal.com@evil.com` (userinfo, поверх AT).
  SEPARATOR-ОСЬ (→queue): `paypal．com`(U+FF0E) · `paypal。com`(U+3002) · `paypal｡com`(U+FF61).
  ЯРУС 2 (→hold при `protected_targets={'paypal'}`): `pаypal.com` · `xn--pypal-4ve.com`.
  ЛЕГИТ-КОНТРОЛИ (→pass): `paypal.com` · `sber.рф` · японский IDN (Han+Kana один label) · корейский

  ЗАПИНЕННЫЕ ОЖИДАНИЯ (блокер-ячейки): `α-testing.com` в host → **queue** (НЕ hold, НЕ pass — честный
  остаточный FP R3) · `α-user@lab.org` → pass · моно-скрипт псевдобренд (`аррӏе.com` / decoded

**S5.3** Зеро-дельта: полный существующий свод гейтов зелёный при включённой оси; любые движения — только

## B6 — Bump-политика пиннутых таблиц [ЗАКРЫТ]
**S6.1** Обновление любой пиннутой таблицы = отдельное AUTHOR_DECISION. Обязательный состав: diff-отчёт
  (добавленные/удалённые/изменённые маппинги + изменённые skeleton) · полный прогон свода гейтов ·
  delta-census с авторизованным манифестом · обновление PIN_MANIFEST (версия+sha256) и памяти.
**S6.2** Рантайм НИКОГДА не тянет таблицы из сети; CI без сети; «latest» запрещён. Инициатор bump —
  только автор (типовой повод: переход UCD, как 16.0→17.0 в [[neighbors-border-138]]-дисциплине).

## B7 — Witness-рендер [ЗАКРЫТ]
**S7.1** Каждый `CONFUSABLE_RELATION_RECORD` рендерится ASCII-безопасно и детерминированно (сорт по
  позиции): original label с раскрытием не-ASCII в `<U+XXXX NAME>` · список скриптов · skeleton ·
  ACE-форма (`xn--…`). Пример: `label 'p<U+0430 CYRILLIC SMALL LETTER A>ypal' scripts=Latin+Cyrillic
  skeleton='paypal' ace='xn--pypal-4ve'`. Без этого канал «смотри глазами» пуст для истинных гомоглифов.
**S7.2** Рендер — в отчёт/witness-канал; `report['text']` остаётся сырым входом (D8, V-OTHER-1).

## B8 — РЕЕСТР ОСТАТКА W7 (именованный) [ЗАКРЫТ — реестр учреждён здесь]
  R1 **whole-script unlisted = ПОЛНЫЙ БАЙПАС** ярусa 1 (измерено: `xn--80ak6aa92e`→`аррӏе`, моно-скрипт,
     mixed-детект слеп). Ловится только ярусом 2 (список) или будущим отдельным фронтом. Тихое расширение
     W7 на whole-script без списка ЗАПРЕЩЕНО (D7).
  R2 4 отложенных маппинга (ѡ→w, η→n, ա→a, ս→u) — маркер-ячейки в батарее; пере-открытие только корпусом.
  R3 Наука-домены (`α-testing.com` в host) = остаточный queue-FP, запинен ячейкой.
  R4 Вне-списочные бренды без яруса 2 = только queue, hold невозможен (длинный хвост).
  R5 Ёмкость очереди: переполненная queue = фактический pass; метрика — на стороне потребителя, W7 её
     не измеряет; честно заявлено.
  R6 r>g численно неизмерим без корпуса атак/легита; публикуется только ИЗМЕРЕННЫЙ FP-набор.
  R7 Видимый-текст-vs-href — вне текстового ядра; фронт режимов B/C.
  R8 Полная UTS#46 IdnaMappingTable не импортирована (только punycode + микро-таблица разделителей, S2.3).
