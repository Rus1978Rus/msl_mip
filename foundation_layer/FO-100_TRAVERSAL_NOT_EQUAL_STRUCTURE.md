ОПРЕДЕЛЕНИЯ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STRUCTURE:
Объект как таковой.
Существует независимо от наблюдателя.
Инвариантна относительно носителя,
времени, количества наблюдателей.
Иерархична — состоит из уровней.

TRAVERSAL:
Способ обхода STRUCTURE наблюдателем.
Всегда унаследован через цепочку
учителей.
Зависит от:
— уровня обхода
— пути
— направления
— OBSERVER_STATE
— CARRIER (носитель)
— METAMODEL
— осознанности

EVALUATION:
Оценка результата TRAVERSAL.
Зависит от:
— самооценки наблюдателя
— внешнего влияния
— образованности / контекста

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ТРИ НЕЗАВИСИМЫХ РАЗРЫВА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

РАЗРЫВ_1: STRUCTURE ≠ TRAVERSAL
Объект не совпадает со способом
его обхода.

РАЗРЫВ_2: TRAVERSAL ≠ EVALUATION
Результат обхода не совпадает
с оценкой результата.

РАЗРЫВ_3: EVALUATION ≠ STRUCTURE
Оценка не совпадает с объектом.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
КЛЮЧЕВЫЕ ПРИНЦИПЫ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STRUCTURE_IS_HIERARCHICAL:
Пример: книга.
L1: буквы/знаки → L2: слова →
L3: абзацы → L4: страницы →
L5: главы → L6: части →
L7: книга целиком.
TRAVERSAL выбирает уровень + путь
+ направление независимо.

OBSERVER_STATE:
С1: не умеет читать → невозможен
С2: не знает языка → частичный
С3: нет METAMODEL → невозможен
    на мета-уровне
С4: неосознанный → выполняется
    без осознания
С5: слепой → требует смены CARRIER
С6: переоценка/недооценка →
    TRAVERSAL выполнен,
    EVALUATION искажена

CARRIER_INDEPENDENCE:
STRUCTURE инвариантна к носителю.
Книга = аудиокнига = Брайль.

TRAVERSAL_IS_INHERITED:
Нет наблюдателя который построил
TRAVERSAL с нуля самостоятельно.
Учитель передаёт инструмент TRAVERSAL
вместе со своим TRAVERSAL.
Без учителя невозможен минимум
на уровне умения читать.

AUTHOR_IS_OBSERVER:
Книга ≠ STRUCTURE.
Книга = TRAVERSAL автора упакованный
в CARRIER для будущих наблюдателей.
Исходная STRUCTURE остаётся
за пределами книги. Всегда.

EXTERNALIZATION_PURPOSE:
Книга / нотация / БД / статья /
табличка — экстернализация STRUCTURE
из мозга во внешний носитель.
Книга = решение проблемы смертности
наблюдателя.

CONVERGENCE_TEST:
Независимые наблюдатели с разными
OBSERVER_STATE → один результат =
СИЛЬНОЕ СВИДЕТЕЛЬСТВО в пользу единой
STRUCTURE (не логическое доказательство:
конвергенция бывает частичной и может
объясняться общими когнитивными
ограничениями или методами — см. C6).
Расхождение = проблема TRAVERSAL
или EVALUATION, не обязательно STRUCTURE.
Ньютон + Лейбниц → исчисление.
Дарвин + Уоллес → эволюция (конвергенция
ЧАСТИЧНАЯ: расходились в механизме отбора).

CHAIN_OF_TRAVERSAL:
Нужны одновременно три вещи:
1. EXTERNALIZATION — зафиксировать
2. CHAIN — живая цепочка учителей
3. CONVERGENCE — множество цепочек

Только носитель без цепочки →
нечитаемая табличка.
Только цепочка без носителя →
искажение через поколения.
Одна цепочка → уязвима к обрыву.

STRUCTURE существует ≠
STRUCTURE доступна.

CASE_5: DELUSION_STRUCTURE (психиатрия)
Разные культурные контексты по-разному

1992) — ВНИМАНИЕ: IPSS документировал
кросс-культурную согласованность течения
и диагностики шизофрении; тезис «единый
нейробиологический опыт, культурно
кодируемый» — интерпретативная надстройка,
НЕ прямая находка IPSS (проверено
первоисточником 2026-07-05).
STRENGTH: PLAUSIBLE / LOOSELY_SOURCED
(атрибуция уточнена после факт-аудита)

CASE_6: SCIENTIFIC_CONVERGENCE (наука)
Независимый TRAVERSAL → СХОДНЫЙ (не
идентичный) результат = свидетельство
в пользу единой STRUCTURE.
Ньютон/Лейбниц, Дарвин/Уоллес —
реальные независимые открытия, НО
конвергенция ЧАСТИЧНАЯ (Дарвин/Уоллес
расходились в механизме отбора:
индивидуальный vs групповой).
STRENGTH: EMPIRICAL / HISTORICAL / PARTIAL

CASE_7: BOOK_HIERARCHY (лингвистика)
Иерархия уровней. TRAVERSAL
выбирает уровень независимо.
STRENGTH: EMPIRICAL / OBSERVABLE
