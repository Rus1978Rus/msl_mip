НАЗНАЧЕНИЕ: реестр КЛАССОВЫХ зависимостей ПОДНАДЗОРНОГО КЛАССА невидимых знаков —
  обязательств уровня КЛАССА, которые НЕ должны блокировать отдельную карточку
  как её дефект. Держит их видимыми, чтобы не потерялись, но и не превращались
  в тупик курицы-яйца для первого образца.

============================================================
ГЛОССАРИЙ ТЕРМИНОВ (канон, введён 2026-07-16 — разведение склеенных имён)
============================================================
- Default_Ignorable_Code_Points — СВОЙСТВО Unicode (General_Category=Cf ∧
  Default_Ignorable_Code_Point=Yes). Техническая ОСНОВА отбора (unicodedata это
  понимает). Не проектная роль, а факт стандарта.
- ПОДНАДЗОРНЫЙ КЛАСС — знаки, о присутствии которых система обязана оставить
  СВИДЕТЕЛЬСТВО (witness). Формально = Default_Ignorable_Code_Points (Cf∧DI = 138
  на UCD 16.0.0; D-NEIGHBORS-BORDER-138). Роль: witness-детекция, максимум полноты.
  [РАНЬШЕ ошибочно — «широкие соседи».]
- ОБРАЗЦЫ — знаки-эталоны ИЗ поднадзорного класса, приведённые В КАРТОЧКЕ как
  представители (в карточке ZWSP: ZWNJ, ZWJ, WJ, BOM, SHY). Роль: модель для
  понимания класса человеком. ОБРАЗЦЫ ⊂ ПОДНАДЗОРНЫЙ КЛАСС. [РАНЬШЕ — «named
  specimens / карточные соседи».]
- LEGACY «сосед / neighbor» — УСТАРЕВШИЙ термин, склеивавший поднадзорный класс и
  образцы в ОДНО. Не использовать. В именах уже закоммиченных файлов и в DECISION_ID
  (D-NEIGHBORS-*, RULE_NEIGHBORS_CRITERION, ORACLE_ZWSP_NEIGHBORS) остаётся как
  исторический КЛЮЧ — файлы/ID НЕ переименовывать.
- ⚠ НЕ ПУТАТЬ: «SPECIMENS» в разделе ниже — ДРУГАЯ сущность, чем ОБРАЗЦЫ. Там
  SPECIMENS = ЗНАКИ, получающие СВОЮ карточку (ZWSP + >=2 для постройки гарда);
  ОБРАЗЦЫ = кодпоинты ВНУТРИ одной карточки. Объединять эти два смысла — отдельное
  решение (это смысл, не переименование).
