НАД гардом. Гард поглощает регистратор. Детект строго ДО нормализации. Не-контаминация
ZWSP обеспечивается аддитивностью + ОБЯЗАТЕЛЬНЫМ acceptance-гейтом (21/21 переприйти
против гарда до мержа). HYBRID_C верен, правится только формулировка контракта.

РЕШЕНИЕ — ДИЗАЙН-СКЕЛЕТ (что закрыто, со счётом)
============================================================
1. АДДИТИВНЫЙ гард, оригинал БИТ-В-БИТ неизменен; НИКОГДА не strip вслепую
   (D2 5/5; P4/P5 доказали разрушение смысла). DEFAULT_IGNORABLE ≠ SAFE_TO_DELETE.
2. КОНТЕКСТ-СВОБОДНЫЙ (Kimi дыра-2, в духе GPT/Qwen/Gemini): гард = чистая механика
   класса detect/annotate/derive; контекст (host/token/…) в гард НЕ входит — он выше
   (риск-слой). Следствие: контекст-гейт-strip в гарде НЕЛЬЗЯ; property-based фильтр
   (напр. Join_Control — никогда не трогать ZWNJ/ZWJ) допустим, т.к. свойство знака.
3. ДВА АРТЕФАКТА (D1 6/6): original (бит-в-бит = сегодняшний поток) + canonical_view
   (производный) + БИКТИВНАЯ карта позиций orig↔canon (P7) + богатые метаданные на
   removed/annotated: {codepoint, class_bucket, original_position, context_window,
   card_mask, schema_version}. «Канонический поток» = ВИД, НЕ замена потока.
4. РИСК-МЭППИНГ — ОТДЕЛЬНЫЙ слой НАД гардом (D3 5/5). Гард может нести ФАКТИЧЕСКИЙ
   presence-сигнал (CLASS_PRESENCE), но НЕ risk-вердикт (CLEAN/POSSIBLE/REAL).
5. ДЕТЕКТ СТРОГО ДО НОРМАЛИЗАЦИИ/STRIP (D5 6/6; P6). Порядок: detect/annotate →
   (опц. derive) → matcher видит оригинал+метаданные. Fail-visible: ошибка гарда →
   сохранить оригинал + GUARD_UNVERIFIABLE, НЕ тихий pass.
6. НЕ-КОНТАМИНАЦИЯ ZWSP: аддитивность (карточный матчер получает идентичный вход) +
   ОБЯЗАТЕЛЬНЫЙ ACCEPTANCE-ГЕЙТ (D4b 5/5): батарея ZWSP 21/21 + mutation-adequacy 5/5
   + oracle ДОЛЖНЫ переприйти против гарда ДО мержа; плюс мутации самого гарда
   (GPT MUT-G1..G7). НЕ через «bypass для карточных» (D4a — меньшинство, отвергнут).
7. ГАРД ПОГЛОЩАЕТ РЕГИСТРАТОР (D6 5/5): единый сканер класса; witness бескарточных →
   выход гарда (не отдельный сканер).
8. ОХВАТ: annotate/witness на все 138 СРАЗУ; тяжёлая policy/strip — консервативно/
   поэтапно (D7 примирение 3/2).

ОБЯЗАТЕЛЬНЫЕ ПОЛЯ/ИЗМЕРЕНИЯ ИЗ D-OTHER (добавлены, никто не отверг):
  - SEQUENCE-SEMANTICS (GPT): поля SEQUENCE_TYPE / SEQUENCE_VALIDITY (ZWJ в эмодзи/tag,
