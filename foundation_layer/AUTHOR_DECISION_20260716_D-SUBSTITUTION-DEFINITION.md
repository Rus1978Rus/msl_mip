РЕШЕНИЕ — ЧАСТЬ ЗАКРЫТА (Q1)
============================================================
SUBSTITUTION = ОТНОШЕНИЕ (двухместное: X ↔ Y взаимозаменяемы), НЕ одноместное
  свойство отдельного знака и НЕ третий отдельный ПЕРЕЧЕНЬ знаков.
ОСНОВАНИЕ: 4/4 ревьюера (Q1) + BY_SPEC-разброс 5–390. «X подменяем» без второго
  знака (и без наблюдателя) не определено: подмена всегда «X ВМЕСТО Y». Разброс
  5–390 = прямое доказательство: одноместного числа «сколько подменяемых» нет,
  каждый исполнитель неявно брал свой контекст → своё число.
FINDING_STATUS (Q1): VERIFIED.

ОГОВОРКА (не сглаживаю): «отношение по природе» ≠ «отдельная ВЫЧИСЛИМАЯ сущность».
  Часть ревьюеров (Qwen, DeepSeek) считают, что для системы ОПОВЕЩЕНИЯ отношение
  РАСТВОРЯЕТСЯ (в кластерах класса / в SIGN_RELATIONS карточек) и отдельно не
  хранится. Т.е. «substitution = отношение» ЗАКРЫТО, а «нужна ли она как отдельная
  структура» — часть OPEN ниже.

O1. ФОРМА отношения — три живых кандидата (расщепление 1/2/1):
   F1. ПАРЫ, параметризованные фильтром: substitution_F(X,Y) — X и Y неразличимы
       для зафиксированного эталонного фильтра F. Матрица/граф пар. [1 ревьюер]
   F2. КЛАСТЕРЫ по вектору атаки / UCD-свойству, БЕЗ фильтра: разбиение класса 138
       на классы эквивалентности (напр. PURE / DIRECTIONAL / TAG / DEPRECATED, или
       по TARGET_KIND — «token breakers / bidi spoofers / …»). Взаимозаменяемы =
       в одном кластере. Инвариант UCD, не зависит от фильтра. [2 ревьюера]
   F3. РАСТВОРЕНИЕ в SIGN_RELATIONS: substitution не отдельная структура, а аспект
       угрозы, описываемый рёбрами карточки знака (BOUNDARY_DISRUPTOR /
       INVISIBLE_CLASS_COLLISION с target_kind). [1 ревьюер]
   Плюрализм фактический: F2 (кластеры, филтр-независимо) имеет перевес 2 из 4, но
   консенсуса нет. ВЫБОР ФОРМЫ — автор.
O2. ЕСЛИ F1 — КАКОЙ фильтр F эталонный (zero-width / Cf / Default_Ignorable).
   Логичный кандидат — Default_Ignorable (тот же, что дал класс 138, единообразие),
   но это отдельное решение. Без выбора F число пар не существует (разброс 5–390).
   NB: F2 и F3 фильтр НЕ требуют — тогда O2 отпадает.
O3. ЧИСЛО — НЕ считать сейчас. После выбора формы:
   - при F1: построить матрицу пар для выбранного F, дать число;
   - при F2: посчитать размеры кластеров (частично уже есть: PURE 23 / DIR 12 /
     TAG 97 / DEP 6);
   - при F3: числа нет, есть карточки со SIGN_RELATIONS.
