## §1 ФАКТ (измерено; §1 пакета + attack-sim координатора)
Кодировка байт→селектор (Paul Butler, 02.2025; не часть Unicode): 0–15 → U+FE00+b, 16–255 →
  U+E0100+(b−16). 256 селекторов = 8.00 бит/знак.
ЖИВАЯ ось W4-VS ловит цепочки, сирот, латинскую и эмодзи-базу. НО: **прикрытие из CJK-знаков с ОДНИМ
  селектором на знак проходило МОЛЧА — 13/50/200/1000/3000 байт → pass, attn=NONE, witness=0**,
  нагрузка восстанавливается побайтово. Причина — приближённая проверка базы (диапазоны CJK/эмодзи)
  в `_vs_verdict`, которую D-W4-VS-AXIS D4 сам пометил как временную («exact emoji-VS/IVD tables are
  a follow-up»). Это цена нашего же D3, вводившего молчание против измеренного эмодзи-флуда.
ATTACK-SIM (координатор, по реальным реестрам; все числа панели воспроизведены НЕЗАВИСИМО и совпали
  до единицы — 29437/15290/1306/742/371):
  - Реестра ТРИ, не два: StandardizedVariants (1306), emoji-variation-sequences (742), IVD (29437).
  - 1002 пары «CJK+FE00» ЗАРЕГИСТРИРОВАНЫ → «закрыть VS1 по диапазону» неверно, нужен точный поиск.
  - FE0F зарегистрирован лишь для 371 базы; у U+1F600 его НЕТ → «эмодзи+FE0F легит по форме» неверно.
  - IVD версионируется ДАТАМИ независимо от UCD (…2022-09-13, 2025-07-14, 2026-07-31, 2026-08-03).
  - P7: из §1-нагрузок санкционировано 0 из 13 и 0 из 200 пар.
  - **IVD использует только 32 селектора (E0100–E011F) ⇒ санкционированно кодируются лишь байты
    16..47 ⇒ ЛЮБАЯ буква или цифра нагрузки структурно НЕсанкционируема** (A=65, a=97, '0'=48).
  - Остаток внутри валидных пар: медиана 1.00, среднее 1.44, max 5.04 бит/база (k до 32 у U+9089).
  - Ценз живого гейта: gate_w4_vs_axis.py = 7 ячеек (frozen baseline).

## ПРИНЯТЫЕ РЕШЕНИЯ (D1–D9)

**D1 — СИГНАЛ: ТАБЛИЧНАЯ ВАЛИДНОСТЬ ПАРЫ, первичный детерминированный вердикт.** Пара
  «база+селектор» вне композитного пина = носитель вне легит-шаблона → скелет D8 (декод →
  экранированное раскрытие → queue). Без порогов и окон В ВЕРДИКТЕ. Отклонены 5/5: структурная форма
  (оставляет 98.8% канала внутри «легита»), энтропия/частотная модель (непиннуема, аналог
  запрещённого скоринга), декод-как-критерий (нарушение D-TAG D5).

**D2 — ПЛОТНОСТЬ (F1): НЕ в first-cut.** Диссент REDTEAM («под attention адаптив молчит») ЗАПИСАН и
  принят как честный остаток BYPASS_VALID_SATURATION. Основание отказа: корпуса японской IVD-прозы
  НЕТ, предложенные пороги разошлись в 10 раз (5% Gemini vs 50% Qwen) — порог в вердикте без корпуса
  есть голосование. Пересмотр — только по именованной полевой метрике.

**D3 — АМЕНДМЕНТ ПРАВИЛА МОЛЧАНИЯ W4-VS.** Предикат SINGLE_ON_BASE переопределяется:
  было «одиночный селектор на базе, похожей на эмодзи/CJK» → стало **«пара (база, селектор)
  присутствует в композитной запиненной таблице»**. Всё прочее — ORPHAN (носитель вне шаблона).
  CHAIN (≥2 смежных) и сирота — без изменений. Ось остаётся ЕДИНСТВЕННЫМ владельцем гейта селектора;
  второго независимого вердикта нет, один вход — одна точка суждения.

**D4 — ЛЕГИТ = КОМПОЗИТ ТРЁХ РЕЕСТРОВ (F5):** IVD_Sequences (пин **2022-09-13**, F3 — ровесник
  нашего UCD 16.0.0; post-pin регистрации 2025-07-14/2026-07-31/2026-08-03 → сигнал до ре-пина,
  остаток RESIDUAL_POST_PIN) + StandardizedVariants 16.0.0 + emoji-variation-sequences 16.0.0.
  Собирается МАШИННО одним парсером, sha256 каждого файла в PIN_MANIFEST. 9 deprecated-пар (PRI 546)
  **держим в вайтлисте** (F4) — документы в дикой природе их содержат.

**D5 — УРОВЕНЬ: queue везде, паритет семейству.** ОБЪЁМ НЕ поднимает уровень (13 и 3000 одинаково —
  единогласно 5/5): длина идёт в witness-метаданные. host = queue (паритет D-INV-GEN), hold НЕ
  возвращается. Одиночная ЗАРЕГИСТРИРОВАННАЯ пара (❤️+FE0F, реальный IVD) → pass, witness 0 —
  молчание, ради которого вводился D3, СОХРАНЕНО.

**D6 — РАСКРЫТИЕ (F2): hex-дамп, кап 64 байта + полная длина + sha256 всей нагрузки + механический
  флаг valid-UTF-8.** UTF-8-превью в first-cut НЕ вводится (диссент SECURITY/GPT записан): текстовая
  нагрузка может нести вложенные VS/TAG, которые «сработают» уже в окне у читателя отчёта.
  ЗАПРЕЩЕНА типизация содержимого («шифртекст/бинарь/малварь») — гипотеза о намерении = семантика
  через раскрытие. Конверт data-only и запрет авто-реинжеста (D-TAG D6/B3) наследуются дословно.

**D7 — ФОРМУЛИРОВКА ЦЕЛИ (переформулировка REDTEAM, принята).** НЕ «закрыть канал», а: **сигнал на
  невалидность пары; канал ДОРОЖАЕТ 8.00 → ~1.4 бит/знак (max 5.04), носитель инфлирует 5.7–8×**.
  Формулировки «сокрытие закрыто» / «VS-стего закрыто» ЗАПРЕЩЕНЫ.

**D8 — РЕЕСТР ОСТАТКА (числа из замера):** BYPASS_VALID_IVD (медиана 1.00 / среднее 1.44 / max 5.04
  бит/база; 58% баз = 0 бит; 100 знаков ≈ 12 байт, подбор богатых баз ≈ 42 байта) ·
  BYPASS_PAIR_CODEBOOK (до 15.26 бит/знак при общем кодбуке сторон) · BYPASS_STDVAR_FE00 (≤1.58) ·
  BYPASS_EMOJI_PRESENTATION_BIT (1 бит/эмодзи, носитель виден глазу) · BYPASS_DILUTION ·
  BYPASS_VALID_SATURATION (диссент D2) · **BYPASS_EMPTY_WITNESS (для шифртекста hex человеку почти
  ничего не говорит — ЧЕСТНО СЛАБЕЕ TAG, где алфавит читаем)** · BYPASS_CROSS_MESSAGE ·
  RESIDUAL_POST_PIN · ADJACENT_MONGOLIAN_FVS (U+180B–180D вне диапазонов оси, FP не возникает).

**D9 — ИНВАРИАНТЫ.** Аддитивно raise-only, fail-open; report['text'] = сырой вход; вывод оси не
  возвращается в analyze() и не идёт в LLM-промпт; движение живого гейта — ТОЛЬКО авторизованным
  delta-манифестом поверх frozen baseline; ОДИН общий проход (не второй сканер).

# СПЕКА: снятие блокеров B1–B8

**B1** F1–F5 решены автором: F1 плотность вне first-cut (D2) · F2 только hex (D6) · F3 пин
  2022-09-13 (D4) · F4 deprecated держим (D4) · F5 композит принят, сборка машинная (D4).

**B2 — ПИН IVD ДАТОЙ, ОТДЕЛЬНО ОТ UCD.** PIN_MANIFEST получает три новые строки с sha256; для IVD
  фиксируется ДАТА РЕЛИЗА (2022-09-13), а не «UCD 16.0.0» — такой версии не существует (замер SIM-D).
  Bump = отдельное author decision + delta-census новых регистраций (паритет B6 W7 / B2 TAG).

**B3 — FAIL-VISIBLE.** Несовпадение/отсутствие любого из трёх файлов → PAIR_STATUS=UNVERIFIABLE:
  запрещены и «assume valid», и «assume invalid and hold everything». Поведение first-cut:
  исключения ПРОДОЛЖАЮТ применяться (иначе флуд), но сопровождаются ВИДИМЫМ системным witness
  «данные валидности непроверяемы — исключения применены без верификации»; молчаливый pass запрещён.

**B4 — DELTA-МАНИФЕСТ (формат панели, принят):** на запись — `cell_id | старое ожидание | новое
  ожидание | правило-триггер | основание (AUTHOR_DECISION + пункт §1) | авторизация`; секция
  CONTROL_UNCHANGED для ячеек, которые НЕ должны сдвинуться; delta-census: число сдвинутых ячеек ==
  числу записей, иначе прогон невалиден (fail-visible).

**B5 — ЗАКРЫТ ЗАМЕРОМ** (SIM-H): frozen baseline = 7 ячеек gate_w4_vs_axis.py (core · heart+VS16 ·
  VS15 text-pres · chain VS16x5 · orphan on letter · orphan leading · supplement chain).

**B6 — ОЖИДАНИЯ ЯЧЕЕК ГЕНЕРИРУЮТСЯ МАШИННО** из запиненных таблиц (включая контрольную 845B+E0100),
  не пишутся руками.

**B7 — ПЕРЕПОДПИСЬ §1** (честность, паритет с переподписью `paypal．com` в W7): формулировка
  «зазор CJK+VS1» НЕВЕРНА — `U+349E+FE00` зарегистрирована, молчать на ней правильно. Дефект —
  **молчание на НЕЗАРЕГИСТРИРОВАННОЙ паре** (напр. `U+845B+FE00`).

**B8 — РЕЕСТР ОСТАТКА (D8) + ЗАПРЕТ «закрыто»** (D7); маркерные ячейки обязательны.

## ПОРЯДОК РЕАЛИЗАЦИИ (каждый шаг — свой гейт)
1. Пин трёх реестров + композитный загрузчик + oracle-гейт. 2. Амендмент `_vs_verdict` (точная пара)
+ delta-манифест. 3. Плагин нагрузки (hex/длина/sha256/utf8-флаг) + витрина. 4. Батарея (ячейки из
свода §2.V5, ожидания машинные). 5. Реестр остатка + оговорка D7.

**Основание r>g:** закрывает измеренный молчащий килобайтный канал детерминированно (0 из 13 и 0 из
200 пар санкционированы; любая буква/цифра структурно несанкционируема), сохраняя молчание на 371
эмодзи-базе и 15290 IVD-базах; порогов в вердикте нет; цена — один машинно собираемый композит
(~1.4 МБ) и один авторизованный манифест. [[FOUNDATION_CONCEPT_PIKETTY_R_G]]
