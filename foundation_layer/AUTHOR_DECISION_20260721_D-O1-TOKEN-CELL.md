============================================================
УТВЕРЖДЁННЫЙ ПАКЕТ «СЕЙЧАС» (что делаем)
============================================================
P0. TOKEN = MEDIUM/queue. Правило эскалации НЕ вводится. Обоснование: silent pass отсутствует
    (ghost уже очередён), а подъём стоил бы 67% ложных hold — hold перестал бы быть сигналом.
P1. КАНОНИЧЕСКАЯ ПРОЕКЦИЯ (схождение 4/5 семейств). Аддитивное поле отчёта для токена, несущего
    члена класса-138: collapse-форма (strip), позиции вставки в исходных координатах, пометка
    PROJECTION. Смысл: «выглядит как paypal; фактически pay<U+FEFF>pal». Чистый свидетель —
    ПОКАЗЫВАЕТ суть, НЕ судит вероятность. Самостоятельна (strip + верифицированная таблица
    класса-138), НЕ требует построенного гарда. ВЕРДИКТЫ НЕ МЕНЯЮТСЯ — растёт только отчёт.
    ЗАПРЕТ: проекция — ТОЛЬКО показ. НИКОГДА не нормализация-для-решения (тихий санитайзер).
P2. ПРАВКА ОЖИДАНИЯ КАРТОЧКИ (Kimi F). RISK_CASE карточки BOM для token: «желательно РЕАЛЬНАЯ» →
    ВОЗМОЖНАЯ, с пометкой «РЕАЛЬНАЯ требует предиката формы коллапса (C6)». Основание: шкала сама
    определяет ВОЗМОЖНАЯ как «часто легитимен, но не освобождается» — это ТОЧНОЕ описание ячейки по
    замеру. Дивергенция reconcile была «желанием без base-rate», а не ошибкой рантайма.
P3. ДИСПОЗИЦИЯ ОТЛОЖЕННОГО ДАННЫМИ: строка PENDING_PREDICATE в реестре O1 (identity-поведение,
    provenance: RECONCILE B3 + FP-замер 2026-07-21, ссылка на C6) + аннотация-гипотеза к вхождению
    «consistent-with: [ghost-token | concat-artifact]». «Не применено» перестаёт быть молчанием.

ОТЛОЖЕНО / ОТДЕЛЬНО / ОТВЕРГНУТО
============================================================
ИНКРЕМЕНТ-2 (измеренный мост к честному hold): C6 — collapse ∈ allowlist ПОТРЕБИТЕЛЯ. Замер даёт
  0% FP / 100% TP на иллюстративном корпусе. ТРЕБУЕТ: обвязки collapse в рантайме, конфига allowlist
  потребителя, СВОЕГО author decision и FP-бюджета на РЕАЛЬНОМ списке. Честные оговорки записаны:
  политико-связан (пустой список → инертен; отсутствие ≠ чисто), ловит имперсонацию ИЗВЕСТНЫХ целей.
ОТДЕЛЬНЫЙ ФРОНТ: E4 CONTEXT_V2 — гранулярность контекст-детектора (корень: «fox <BOM>jumps»
  сворачивается в BYTE_EXACT_TOKEN). Трогает верифицированный путь (читается всеми карточками) →
  СВОЙ конвейер + полная ре-валидация, как O(n²)-фикс. Не закрывать этой ячейкой.
ОТВЕРГНУТО: (i) прямой token→HIGH (5/5 + 67% FP); (ii) C1 strict-infix как самостоятельный предикат
  hold (36% FP, коррелят); (iii) ОБЩИЙ словарь (промахивается по «paypal» — оно нормальное слово) и
  СИСТЕМНЫЙ словарь (семантический дрейф против «структура без смысла»); (iv) НОРМАЛИЗАЦИЯ НА ВХОДЕ
  — тихий санитайзер, уничтожает байтовую разницу, которую эксплуатирует ghost.
ПРИОРИТЕТ ВНУТРИ ОЧЕРЕДИ (4 ноги): признан полезным, но требует контракта потребителя/UI —
  ПЛАНИРУЕТСЯ, не отгружается этим пакетом.
