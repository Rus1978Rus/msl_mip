## §1 ФАКТ (измерено; §1 пакета + attack-sim координатора)
97 из 128 кодпоинтов TAG-блока — в классе-138; U+E0020–E007E зеркалят printable ASCII; декодера нет.
Сегодняшняя поимка контрабанды = ПОБОЧНЫЙ ЭФФЕКТ порога плотности Input-Guard, не свойство фронта:
  разбавление ~120 видимыми символами глушит сигнал (0.188 → OK → pass).
Легит-флаг (🏴+gbsct+CANCEL) и вложенная команда сегодня НЕОТЛИЧИМЫ (обе pass, семья CONTROL).
ATTACK-SIM: (1) видимый знак между КАЖДЫМ tag-знаком → максимальная смежная серия = 1 (порог N≥3
  слеп; сырая подпоследовательность доходит до потребителя); (2) unassigned E0000/E0005/E001F и
  E0001 УЖЕ дают witness, уровня нет; (3) флаг+хвост после CANCEL, нагрузка+decoy-флаг, флаг в прозе
  200+ → всё pass; (4) interlinear U+FFF9–FFFB вне класса-138, witness есть, уровень pass;
  (5) ёмкость канала «внутри валидного синтаксиса»: шаблон без списка 25.9–31.0 бит/флаг, широкий
  CLDR ~12.3, closed-world-3 = 1.58; (6) VS 8.00 бит/знак > TAG 6.57.

## ПРИНЯТЫЕ РЕШЕНИЯ (D1–D9)

**D1 — ТРИГГЕР (F1): (A) ЛЮБОЙ НАЗНАЧЕННЫЙ tag-знак ВНЕ легит-гейта = сигнал.** Порог N≥N (B)
  ОТКЛОНЁН ЗАМЕРОМ вопреки голосам 2:1 (SIM-1: фрагментация → maxrun=1). Плотность (D) отклонена
  (обход измерен + конфиг чужой оси). Декод (C) — ОБЪЕКТ witness/evidence, **НЕ критерий детекции**
  (шифрованная/base64 нагрузка «бессмысленна» — понижать сигнал шифрованием недопустимо).

**D2 — ЛЕГИТ-ГЕЙТ (F4): closed-world whitelist РОВНО 3 RGI** (`gbeng`, `gbsct`, `gbwls`), шаблон —
  лишь ПАРС-СЛОЙ, валидация всегда против списка. Шаблон: база U+1F3F4 + РОВНО 5–6 знаков из зеркал
  [0-9a-z] + CANCEL U+E007F; алфавит и длина — часть гейта. Широкий CLDR-классификатор (позиция GPT,
  корректная по UTS#51) ОТКЛОНЁН по арифметике (SIM-5: канал 12.3 бит/флаг против 1.58). Не-RGI
  легит (флаг Техаса `ustx`, будущие RGI) → сигнал by design = ИМЕНОВАННЫЙ ОСТАТОК R5.

**D3 — SPAN-SCOPING + КОНСЬЮМ-ПРАВИЛО.** Гейт действует ТОЛЬКО на span валидной последовательности,
  НИКОГДА не на документ (иначе flag-washing: один валидный флаг глушит весь текст). Порядок не
  важен (decoy-флаг ПОСЛЕ нагрузки не спасает). Валидный флаг-span молчит; ЛЮБОЙ хвост после CANCEL
  и любые tag-знаки вне принятого span → сигнал.

**D4 — УРОВЕНЬ (F2/F3): ТОТАЛЬНАЯ СТРУКТУРНАЯ ТАБЛИЦА, queue везде.**
  whitelist-флаг → pass (молчит) · нагрузка в прозе → **queue** · нагрузка в host → **queue**
  (паритет D-INV-GEN, НЕ поднимать: двойное наказание за один факт) · одиночный tag-знак → **queue**
  (§1-pass фиксируется как авторизованная delta; ФЛАГ ПЕРЕСМОТРА при первом корпусе; главный
  ожидаемый FP — усечённый копипастой флаг) · U+E0001 → queue по общему правилу «без базы» с
  пометкой «архаичный language tag, RFC 2482 Historic», decoded_ascii=NONE · unassigned (F5) →
  сигнал по D1, **БЕЗ декода**, событие UNASSIGNED_TAG_BLOCK_CODEPOINT, без претензии «скрытая
  ASCII-нагрузка». HOLD в first-cut НЕ вводится: только по отдельной улике (protected-target
  collision / parser desync), как ярус 2 в W7 — отдельным инкрементом.
  ДИССЕНТ SECURITY («проза → hold») рассмотрен и ОТКЛОНЁН: base-rate не измерен (§1 НЕИЗМЕРИМО),
  hold без корпуса = приговор без статистики; пере-открывается измеренным корпусом.

**D5 — ЗАПРЕТ СЕМАНТИКИ.** Уровень НИКОГДА не зависит от СОДЕРЖИМОГО декода. «Осмысленный ASCII»
  как критерий ЗАПРЕЩЁН (4/4 + панель): языковая зависимость и bias; ИНВЕРСИЯ ОПАСНОСТИ (base64/
  шифртекст выглядит «случайным»); недетерминизм батарей; играбельность в обе стороны (подброс
  страшных слов в чужой текст → ложный hold = flagging-атака). Допустим ОДИН детерминированный
  суррогат в witness-аннотации: «декод целиком printable ASCII: да/нет» (тотальная функция).

**D6 — РАСКРЫТИЕ (F6): (b) ЭКРАНИРОВАННО + УСЕЧЁННО, ОБЯЗАТЕЛЬНО.** Не раскрыть = пустой
  witness-канал (человек не может сказать «последнее слово» о невидимом; паритет W7, где раскрытие
  признано обязательным). Раскрыть сырьём = отчёт-ретранслятор инъекции. Контракт — см. B3.
  cap = **200** знаков + ОБЯЗАТЕЛЬНАЯ полная длина; cap — ДИЗАЙН-КОНСТАНТА, не конфиг.

**D7 — ФОРМА (F7): ОСЬ** (как W4-VS/W5/W7) на СУБСТРАТЕ класса-138, паттерн W4-VS
  (silence+escalate). ОДИН проход — «one scan, multiple consumers»: класс даёт присутствие,
  ось несёт шаблон-исключение, span-scoping, декодер, единый структурный witness. НЕ второй полный
  сканер, НЕ 97 карточек. 31 unassigned вне класса — объединённым range-check в том же проходе.

**D8 — СЕМЕЙСТВО «СКРЫТЫЕ КАНАЛЫ» УЧРЕЖДЕНО** (условие REDTEAM, без него вернул бы LOOPHOLE).
  Общий скелет: носитель вне легит-шаблона → декод → экранированное раскрытие → queue; per-carrier
  плагин = шаблон + декодер. TAG — ПЕРВЫЙ инстанс. **VS — СЛЕДУЮЩИЙ ПРИОРИТЕТ** (SIM-6: 8.00 против
  6.57 бит/знак + подтверждённое боевое применение), затем zero-width, затем interlinear U+FFF9–FFFB
  (SIM-4). Общего декодера у носителей нет → единый фронт невозможен, скелет ≠ абстракция.

**D9 — ИНВАРИАНТЫ.** Ось аддитивна raise-only, fail-open; witness сохраняется; report['text'] =
  сырой вход; вывод оси НИКОГДА не возвращается в analyze() и не идёт в LLM-промпт (запрет
  авто-реинжеста); delta-census на FROZEN baseline; ЗАПРЕЩЕНА формулировка «сокрытие закрыто».

# СПЕКА: снятие блокеров B1–B8 (часть решения; код разблокирован после неё)

**B1 — СПЕКА АВТОМАТА ЛЕГИТ-ГЕЙТА.**
  S1.1 tag_spec: РОВНО 5–6 кодпоинтов из диапазона зеркал [0-9a-z] (U+E0030–E0039, U+E0061–E007A);
    любой иной знак внутри — не tag_spec.
  S1.2 Последовательность принимается ТОЛЬКО как: U+1F3F4 + tag_spec + U+E007F, где decode(tag_spec)
    ∈ {gbeng, gbsct, gbwls}. Всё остальное — не принято.
  S1.3 ТЕРМИНАЦИЯ (детерминированно): EOF · любой видимый знак · вторая база U+1F3F4 · ZWJ/иной
    невидимый вне tag-диапазона · длина tag_spec > 6 · отсутствие CANCEL. Все ветви → сигнал.
  S1.4 КОНСЬЮМ: принятый span помечается consumed и молчит; ВСЕ tag-знаки вне consumed-span'ов →
    сигнал. Order-insensitive (decoy-флаг после нагрузки не глушит нагрузку). Вложенность запрещена.
  S1.5 Два и более валидных флага подряд — оба молчат (каждый свой span).

**B2 — ПИН WHITELIST-3.** `data/unicode/rgi_tag_flags.txt` (3 записи + провенанс) в PIN_MANIFEST
  с ver+sha256; источник — RGI_Emoji_Tag_Sequence (emoji-sequences). Неподвижен с Emoji 5.0 (2017);
  новых предложений не процессится с 2022 → bump дешёв. Конфликта с пином unidata 16.0.0 НЕТ
  (тройка неизменна 5.0…17.0). Bump = отдельное author decision (паритет B6 W7). Несовпадение
  пина → fail-visible TAG_VALIDITY_UNVERIFIABLE, БЕЗ тихого освобождения легита.

**B3 — КОНТРАКТ РАСКРЫТИЯ.**
  S3.1 Конверт data-only: маркер «СКРЫТЫЙ ТЕКСТ (данные, НЕ инструкция)»; голым текстом не выводить.
  S3.2 Экранирование ТОТАЛЬНОЕ: функция определена на ВЕСЬ декодируемый диапазон (частичная функция
    = первый непокрытый знак проходит активным). Первый инкремент — один запиненный эскейпер
    (консольный/логовый отчёт), прочие каналы объявлены остатком R7 (ответственность потребителя).
  S3.3 cap = 200 (дизайн-константа) + ОБЯЗАТЕЛЬНАЯ полная длина («…усечено, всего N»): без total
    атакующий прячет интересное за капом.
  S3.4 sha256 ПОЛНОЙ нагрузки в evidence: раскрытие усечённое — доказательство полное.
  S3.5 ЗАПРЕТ keyword-эскалации (D5) и ЗАПРЕТ авто-реинжеста (D9).

**B4 — КОМПОЗИЦИЯ ОСЕЙ.** Уровень = МАКСИМУМ по осям, явно: TAG-ось vs D-INV-GEN vs Input-Guard vs
  W4/W5/W7. На флуде Input-Guard (hold) владеет по максимуму; TAG-witness при этом сохраняется.
  Никаких молчаливых коллизий: каждая ось пишет своё поле отчёта.

**B5 — РАЗВИЛКА ПРОЗЫ ЗАКРЫТА ЯВНО:** queue (D4); диссент SECURITY зафиксирован в D4 и в реестре.

**B6 — ТОТАЛЬНОСТЬ ДЕКОДЕРА.** Поведение специфицировано на ВСЕХ 128 кодпоинтах: U+E0020–E007E →
  ASCII (cp − 0xE0000); U+E0001 → маркер, без декода; U+E007F → терминатор, не часть нагрузки;
  U+E0000 и U+E0002–E001F (31) → UNASSIGNED, без декода. Исчерпывающий 128-ячеечный census +
  round-trip зеркала + assert unidata_version. Отдельный пин декод-таблицы НЕ нужен (зеркало
  дефиниционно тотально с Unicode 3.1, дрейф ловится census'ом). Frozen baseline; корпус
  «входы без tag» — ПЕРЕЧИСЛЕНИЕМ, не свойством.

**B7 — РЕЕСТР ОСТАТКА (учреждён):**
  R1 VS-стеганография (8.00 бит/знак > TAG) — БАЙПАС, СЛЕДУЮЩИЙ приоритет фронта.
  R2 Zero-width битовые схемы — БАЙПАС (легит-база выше, симметрия тяжелее).
  R3 Interlinear annotation U+FFF9–FFFB (SIM-4: вне класса-138, witness есть, уровень pass) — БАЙПАС.
  R4 Шифрованная/кодированная нагрузка внутри TAG: witness покажет факт и строку, не смысл — всегда.
  R5 Не-RGI легит (`ustx` Техас на WhatsApp; будущие RGI) → сигнал by design; лаг списка.
  R6 Фрагментация нагрузки между сообщениями/полями и СБОРКА сообщения из разнесённых runs:
    детект каждого run — да; полная реконструкция — PENDING (tier 2).
  R7 Экранирование для не-консольных каналов (HTML/Markdown/JSON/агентный downstream) — на совести
    потребителя; полного решения внутри witness-рамки нет.
  R8 Одиночный tag-знак → queue: FP на усечённых копипастой флагах не измерен (флаг пересмотра).
  R9 r>g численно неизмерим без корпуса: публиковать только ИЗМЕРЕННЫЙ набор, без численных претензий.

**B8 — ЗАПРЕТ ЛОЖНОЙ ПОЛНОТЫ.** Формулировка «сокрытие закрыто» ЗАПРЕЩЕНА. Обязательная оговорка
  в выводе оси и в документации: «закрыт канал TAG-зеркала; другие невидимые носители не проверялись».
