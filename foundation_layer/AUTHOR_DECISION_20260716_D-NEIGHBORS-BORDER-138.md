============================================================
1. ПРЕДИКАТ ГРАНИЦЫ КЛАССА = Cf ∧ Default_Ignorable_Code_Point (= 138 на UCD 16.0.0).
   Условия ¬BN, ¬tag, ¬deprecated УБИРАЮТСЯ (они были авторским сужением, прозой
   не диктовались). Соседей ZWSP = 137 (138 минус сам U+200B).

2. ВКЛЮЧЕНЫ ВСЕ 4 ПОДГРУППЫ:
   - PURE (23): чисто невидимые нулевой ширины (ядро);
   - DIRECTIONAL (12): LRM/RLM/ALM/embeddings/overrides/isolates — АКТИВНАЯ угроза
     (Trojan Source);
   - TAG (97): language tag + tag-символы — СПЯЩАЯ угроза (LLM-инъекции);
   - DEPRECATED (6): 206A-206F — для полноты класса.

3. ОБЯЗАТЕЛЬНЫЙ ВТОРОЙ СЛОЙ — РИСК-ГРАДАЦИЯ (без неё 97 тегов утопят сигнал):
   witness ФИКСИРУЕТ присутствие на ВСЕХ 138; RISK назначается ПО ПОДГРУППЕ:
     - DIRECTIONAL → ВЫСОКИЙ (Trojan Source, активная подмена порядка);
     - PURE       → ПО КОНТЕКСТУ (в домене/идентификаторе выше, во FREE_TEXT ниже);
     - TAG        → ЗАМЕЧЕН / НИЗКИЙ (следим, не кричим);
     - DEPRECATED → НИЗКИЙ.
   Детекция максимальна, тревога градуирована. «Максимум по классу» ≠ «максимум по
   тревоге».

4. ЭТО WITNESS-ГРАНИЦА (кто в классе для ФИКСАЦИИ присутствия), НЕ разрешение на
   удаление. Граница «класс ≠ взаимозаменяемость ≠ SAFE_TO_DELETE» РАСШИРЯЕТСЯ:
     - НЕЛЬЗЯ удалять directional из легитимного биди (арабский/иврит);
