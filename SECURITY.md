# Security Policy / Политика безопасности

## English

**MSL/MIP is a research prototype, not a production validator, antivirus, or
security guarantee.** It is a witness/alerting tool: it recommends, it does not
decide. See the LICENSE — all rights reserved.

### Reporting a problem privately

If you find a security problem, a false result, or a way to evade detection,
please report it **privately** — do not open a public issue first.

Preferred channel:
1. **GitHub private vulnerability reporting** — on this repository, use the
   "Report a vulnerability" button under the **Security** tab. This reaches the
   author privately.
2. If that is unavailable — Telegram: open the app and message the user whose
   handle is **Malyavsky1** (type the "@" and the name yourself). The link is
   written this way on purpose so automated harvesters do not scrape it.

Please include: what you tried (the input), what happened, and what you
expected. A short reproducible example helps most.

There is no bug-bounty program and no guaranteed response time — this is a
private authored project. Reports are welcome but create no obligation.

## Русский

или гарантия безопасности.** Это инструмент-свидетель/оповещатель: он

### Как сообщить о проблеме приватно

Если нашли проблему безопасности, ложный результат или способ обойти детекцию —
сообщите, пожалуйста, **приватно**, не открывая сразу публичный issue.

Предпочтительный канал:
1. **Приватный отчёт GitHub** — на этом репозитории кнопка «Report a
   vulnerability» во вкладке **Security**. Отчёт приходит автору лично.
2. Если недоступно — Telegram: откройте приложение и напишите пользователю с
   ником **Malyavsky1** (символ «@» и ник наберите сами). Ссылка записана так
   намеренно — чтобы автоматические сборщики не выгребли её на спам.

Опишите: что вы попробовали (входные данные), что получилось и что ожидали.
Короткий воспроизводимый пример помогает больше всего.

Программы вознаграждений (bug bounty) нет, гарантированного срока ответа нет —
это частный авторский проект. Отчётам рады, но обязательств они не создают.
