# Три наблюдателя: инвариантность канонизации, три оси и fail-closed фронтир

## 0. Отправная точка
Автор предложил приложить методологию карточек знаков/цифр к уравнению Шрёдингера
(iℏ ∂ψ/∂t = Ĥψ) и обратно — по одной карточке, по две, все сразу, затем «0и1», затем
«1и0». Проверяемый тезис методологии: **знак судится по тому, что он ДЕЛАЕТ в контексте,
а не по начертанию.**

## 1. Мост «карточки ↔ Шрёдингер»
Уравнение прочли как набор знаков. Часть аналогии — настоящий механизм:

- **ψ → |ψ|²** (правило Борна) = «канонизация до доверия»: сырой знак не наблюдаем,
  сначала обработай, потом доверяй. **[механизм]**
- **Контекст = базис измерения; канонизация = коллапс.** **[рифма, сильная]**
- **Некоммутативность «0и1 ≠ 1и0»** = зависимость результата от ПОРЯДКА декодирования =
  дискретный корень принципа неопределённости (ÂB̂ ≠ B̂Â). **[механизм]**
- **`i`** — крошечный знак-carrier: убери его — уравнение волны становится уравнением
  диффузии. Один атом пересобирает природу физики. **[механизм/рифма]**
- «Уравнение ЕСТЬ карточки» целиком — **[метафора]**: общего детерминированного
  канонизатора между семантикой знаков и физикой нет.

## 2. Демо коммутатора (единственная проверяемая прогоном часть)
Артефакт: `tools/canon_commutator_demo.py`. Две операции — percent-декод `P` и наивный
фильтр `F` (удалить литеральный `../`). Вердикт: осталось ли `../` (обход каталога).

- **Порядок решает:** `F(P(s))` и `P(F(s))` дают РАЗНЫЙ вердикт на `%2e%2e/…` —
  коммутатор [P,F] ≠ 0.
- **Глубина** (`%252e`): одного прохода мало, нужен декод ДО НЕПОДВИЖНОЙ ТОЧКИ.
- **Стирать нельзя:** на `....//` фильтр САМ создаёт `../`. Только обнаруживать.
- **Декод до неподвижной точки возвращает порядко-независимость** = инвариантность
  к мутации (один вердикт при любой маскировке).

## 3. Лестница наблюдателей
Эксперимент: помещаем «наблюдателя» (агента-измеритель) в цепь и смотрим, что меняет
его присутствие. Знак до измерения — в суперпозиции ролей; КОНТЕКСТ = базис; чтение =
коллапс в одну роль + риск.

- **0 наблюдателей.** Детерминированная программа: один ответ, от взгляда не зависит.
  (Напоминание: «наблюдатель» в физике — не сознание, а взаимодействие/декогеренция.)
- **1 наблюдатель.** Тот же знак «0» коллапсирует в 4 роли по контексту
  (число / хост / двойник буквы / NUL). Поверхностное чтение обманывается (LOW),
  после канонизации — верно (HIGH). Три кодировки одного смысла сходятся в одну точку.
- **2 наблюдателя** — A (базис «URL/сеть») и B (базис «свободный текст»).
  - ДО канона: разошлись на ВСЕХ шести знаках. A систематически перебарщивает,
    B недооценивает.
  - ПОСЛЕ общего канона: сошлись на всех шести — по ДВУМ осям (см. §4).
- **3 наблюдатель** — красная команда (C). Честно применяя тот же канон, СЛОМАЛ
  согласие A=B, уведя смысл в алфавиты, которые percent-декод не покрывает.

Атаки C:
1. **Смугглинг смысла** (тот же `../etc/passwd`/NUL мимо канона → ложноотрицательное):
   overlong-UTF-8 (`%c0%ae`→`.`), полноширинные/NFKC (`．．／`), HTML-entity
   (`&#46;&#47;`), NUL мимо канала (`&#0;`, `%c0%80`).
2. **Расщепление инварианта** (один смысл → разные формы): `.` vs `%c0%ae` vs `．`
   vs `..​/`; host-нотации `127.0.0.1` = `2130706433` = `0x7f.1`.
3. **Дуальная коллизия use/mention**: настоящий `%2f`-слэш и предложение
   «не пропускай `%2f`» канон сводит к одной форме — портит текст-о-кодировке и
   делает его формально «содержащим слэш». Канон не инъективен и не сохраняет смысл.

## 4. Три оси согласия
1. **Структура** — канон покрывает → один вердикт (`../etc/passwd`, `%00` → HIGH).
   **[механизм]**
2. **Применение/контекст** — канон дать не может → честное «КОНТЕКСТ-ЗАВИСИМО»
   (`0.0`, `192.168.0.1`, `g00gle`, `..`). **[граница; подтверждает: канонизация
   структуры ≠ определение функции]**
3. **Полнота канонизатора** — согласие держится ЛИШЬ в пределах покрытых алфавитов;
   A=B было артефактом ограничения входа percent-алфавитом. **[вклад красной команды]**

## 5. Когда согласие ВОССТАНОВИМО
Канон должен быть не одним декодером, а **join (объединением) эквивалентностей ВСЕХ
объявленных приёмников**, прогнанным до СОВМЕСТНОЙ неподвижной точки:

```
percent-decode -> UTF-8-overlong(resolve/reject) -> NFKC/confusable-fold
  -> entity-decode(гейт по HTML-sink) -> zero-width-strip -> bidi-normalize
  -> host-IP-normalize
```

Стадии НЕ коммутируют (полноширинный `％`: decode-сначала ≠ normalize-сначала) →
нужна решётка + итерация до конвергенции, ЛИБО fail-closed при остаточной
неоднозначности.

## 6. Принципиальный фронтир (не закрыть НИКАКИМ конечным каноном)
1. **use vs mention** — «данные для интерпретации» или «текст ОБ кодировке»? Из строки
   неразрешимо (привкус теоремы Райса). Нужен контекст, которого в строке нет.
2. **Открытое множество приёмников** — атакующий всегда постулирует новый sink (новый
   confusable, легаси-декодер). Канон конечен; пространство кодировок открыто.
3. **Неустранимая двойственность** — часть строк честно бивалентны (и benign, и
   malicious по sink'у). Нельзя одновременно иметь сохранение смысла И инъективность,
   когда базовые отношения конфликтуют.

Единственное закрытие фронтира — **не канонизация, а ПОЛИТИКА**: «канонизируй до
совместной точки; если под полной решёткой sink'ов форма не единственна → REJECT
(fail-closed)» + контекст-гейт по типу приёмника. Дыра переводится из провала
корректности в цену доступности.

## 7. Суть (без мистики)
**Смысл знака задаёт распознаватель (sink), а не строка.** Один распознаватель → есть
каноническая форма и наблюдатели сходятся; распознавателей много и множество открыто →
единой канонической формы не существует В ПРИНЦИПЕ. Это языко-теоретический предел, а
не квантовая магия. «Наблюдатель» здесь = выбранный распознаватель; согласие достижимо
только внутри заранее ОБЪЯВЛЕННОГО общего мира.

## 8. Следствия для CANONICALIZATION_PRE_PASS (карточки цифр, Q1–Q4)
- **Q1 (где живёт pre-pass):** до scan_signs, как объявленная композиция декодеров.
- **Q2 (глубина):** декод до СОВМЕСТНОЙ неподвижной точки по решётке декодеров, с
  лимитом проходов против decode-loop.
- **Q3 (контекст):** опасные декодеры (entity, host, bidi) — гейтировать по типу
  приёмника; use/mention оставлять как открытую границу (помечать, не выдавливать).
- **Q4 (не-ASCII цифры / confusables):** NFKC/confusable-fold — обязательная стадия
  канона, иначе `．．／` проходит мимо.
- **Политика на границе:** остаточная неоднозначность → fail-closed (совместимо с
  рамкой «свидетель, не судья»: не «пропустить молча», а «поднять тревогу/удержать»).
