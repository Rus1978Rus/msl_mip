§1. КОНВЕРГЕНЦИЯ (все 4 входа — считать УСТОЯВШИМСЯ)
============================================================
- Плотность (D) ОТКЛОНЕНА как детектор: обход разбавлением измерен (§1 пакета), плюс порог —
  конфиг DoS-оси => тот же вход даёт разный сигнал на разных сборках (смешение осей).
- Декод нагрузки ОБЯЗАТЕЛЕН, но как ОБЪЕКТ witness/evidence, НЕ как критерий детекции
  (C-как-триггер мёртв: шифрованная/base64 нагрузка «бессмысленна» — понижать сигнал шифрованием нельзя).
- Раскрытие = (b) ЭКРАНИРОВАННО + УСЕЧЁННО (4/4). Не раскрыть = пустой witness (человек не может
  сказать «последнее слово» о невидимом; паритет W7). Раскрыть сырьём = отчёт-ретранслятор инъекции.
- Проза = queue (3 из 4; диссент SECURITY «hold» зафиксирован, см. F3).
- «Осмысленный ASCII» ЗАПРЕЩЁН как критерий уровня (GPT + все стойки панели; Qwen согласен, что
  влияет лишь на приоритет): языковая зависимость, bias, ИНВЕРСИЯ ОПАСНОСТИ (base64/шифртекст
  выглядит «случайным»), недетерминизм батарей. Допустим детерминированный суррогат в witness:
  «декод целиком printable ASCII: да/нет».
- Форма: НАДСТРОЙКА над классом-138 по паттерну W4-VS (silence+escalate), ОДИН проход —
  «one scan, multiple consumers»; не второй полный сканер, не 97 карточек.
- «TAG закрыт» != «сокрытие закрыто»; VS/zero-width/interlinear — отдельные оси с ярлыком БАЙПАСС.

§2. ATTACK-SIM НА ЖИВОМ ЯДРЕ (мои замеры 2026-08-04 — бьют голоса)

SIM-1 (F1 — РЕШАЕТ РАЗВИЛКУ ПРОТИВ БОЛЬШИНСТВА). Фрагментация нагрузки видимым знаком между

  Порог N>=3 (Grok+Qwen, 2 голоса) не увидел бы её ВООБЩЕ. Потребитель (LLM/парсер) читает сырой
  текст, где подпоследовательность tag-знаков сохранена. ДОПОЛНИТЕЛЬНО: даже НЕфрагментированная
  9-знаковая нагрузка сегодня -> pass (ig=OK) — короткая нагрузка ниже порога плотности.
  ВЫВОД: B мёртв как детектор; A (любой назначенный tag вне легит-гейта) — единственный триггер,
  устойчивый к измеренному обходу. GPT + панель ПРАВЫ против счёта 2:1.
SIM-2 (F5 — ПОПРАВКА К ПАНЕЛИ ЗАМЕРОМ). Unassigned tag-кодпоинты (U+E0000, U+E0005, U+E001F) и
  U+E0001 СЕГОДНЯ УЖЕ ДАЮТ witness=1, attn=WITNESS_PRESENT, уровень pass — хотя они ВНЕ класса-138.
  => Утверждение панели «31 unassigned БЕЗ витнесса» НЕВЕРНО (витнесс есть, нет только уровня);
  утверждение Qwen «pass, не в классе-138» верно по уровню, неполно по витнессу. Значит range-check
  для 31 кодпоинта нужен для УРОВНЯ/классификации, а не чтобы «завести витнесс с нуля».
SIM-3 (базис легит-гейта). Валидный флаг Шотландии один -> pass (ig=OK, доля невидимых 0.857, но
  ниже порога длины). Флаг + хвост ПОСЛЕ CANCEL -> pass. Нагрузка + decoy-флаг ПОСЛЕ -> pass.
  Флаг в прозе 200+ -> pass. => Сегодня легит-флаг молчит правильно, но и вся контрабанда рядом с ним
  молчит тоже; консьюм-правило (флаг-span молчит, хвост сигналит) и order-insensitive span-scoping
  ОБЯЗАТЕЛЬНЫ, иначе flag-washing.
SIM-4 (V6 #3 — НОВЫЙ НОСИТЕЛЬ ПОДТВЕРЖДЁН). Interlinear annotation U+FFF9/FFFA/FFFB: ВНЕ класса-138,

SIM-5 (F4 — АРИФМЕТИКА РЕШАЕТ СПОР О СПИСКЕ). Ёмкость скрытого канала «внутри валидного синтаксиса»

  в ~8-20 раз и упирает атакующего в десятки ВИДИМЫХ флагов (неконспиративно) + DoS-рубеж.
