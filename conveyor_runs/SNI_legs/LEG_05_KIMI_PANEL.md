### V3. ЭМОДЗИ-ПРЕЦЕДЕНТ

**Образец — по ПРИНЦИПУ, не по ФОРМЕ. 4/4.** Правило эмодзи-исключения: **нормативный, версионно-запиненный, замкнутый, детерминированный источник; решение per-позиция; ноль корпуса**. Форма — конечный список последовательностей (RGI, 1468, замерено RESEARCH). Для письменностей конечного списка строк не существует (словарь кхмерского открыт), но принцип переносим полностью — RESEARCH измерил три промышленные модели нормативного допуска невидимок: замкнутый список строк (RGI; IVD — 39 303 последовательности, версия 2022-09-13) и **замкнутый набор контекстных правил (UTS#39 §3.1.1: A1 — разрыв курсивной связи, A2/B — вирама-конъюнкты, + Script Restriction + NFC)**. Замена RGI-формы: нормативное СВОЙСТВО вместо нормативного списка (lb=SA / InCB / JT) — это и есть рекомендованный V1=B.

**Защита от «карточка = набор частных случаев» (FP):** ОДНО обобщающее правило («функциональная позиция по нормативному свойству — не аномалия») вместо перечисления: таблица из трёх строк (ZWSP→SA-письменности, ZWJ→вирама-конъюнкт, ZWJ→эмодзи-RGI) вместо 8–9 поодиночных исключений. Обобщение дешевле перечисления — и по читаемости, и по числу микроканалов. Каждый будущий carve-out — только с ярлыком и ячейкой-стражем в том же манифесте (наследие BYPASS_LIGATURE/AFTER_R). Перепись микроканалов (REDTEAM): E — 2 именованных (оба обложены/наследованы); A-any — 3; A-dom — 2, один с нулевым налогом; D — 0 новых, но хроническая инфляция queue.

### V-OTHER. ПРЯМЫЕ ОТВЕТЫ

**«Карточный слой трогать нельзя, гасить выше» — ОТКЛОНЕНО 4/4.** Цена отказа измерена: queue на 100% нормального текста 7 письменностей навсегда — это не остаток, а отказ от письменностей (FP); очередь, систематически ложная для целых языков, обучает пользователя игнорировать очередь — инфляция собственной валюты проекта (REDTEAM). «Гасить выше» = либо (iii) по эффекту (цена не снята), либо скрытая потребительская настройка (нарушение ПРАВИЛА ПОРОГА, VERIFY). REDTEAM оставляет автору архитектурный выбор РАЗМЕЩЕНИЯ дельты (карточный слой или гашение в релейшн BOUNDARY_DISRUPTOR — источнике эскалации по §1): замеры инвариантны к этажу, но вопрос амнистии слой не снимает — A-any/A-dom одинаково дырявы на любом этаже.

**«Это тот же вопрос, что C6/CONTEXT_V2?» — НЕТ, 4/4.** C6 — о непознаваемом (намерение). Здесь судится **функция позиции** — познаваемый факт стандарта: строка несёт скрипт и соседство, таблицы запинены; намерение не судится нигде. Пересечение с C6 ровно одно — на функциональной позиции бит vs разделитель непознаваем — и оно уже именовано LIMIT'ом. Основание «стоимость ввода» — мотивировка, не механизм (см. §2 ответ 2).

**«Честнее ли на уровне ПОТРЕБИТЕЛЯ?» — НЕТ для вердикта, 4/4 (коллизия с ПРАВИЛОМ ПОРОГА).** «Потребитель знает язык» как вход вердикта = языковая настройка через потребителя — запрещена наследием R4 как D5 по эффекту: градиент уязвимости (атакующий целится в инсталляции с кхмерским профилем) + census теряет объект. Маршрутизация ОТОБРАЖЕНИЯ (как подсвечивать) допустима по R4, но queue не снимает — критерий (а) недостижим на этом пути. Зафиксированное различие (R4, подтверждено): зависимость от свойства СТРОКИ (скрипт соседей из пин-таблиц — детерминированный разбор) ≠ зависимость от потребителя (запрещённая настройка).

## §5. RECOMMENDATION

### Обязательные поправки (условия «дизайн верен»)

1. **V1 = E, B-первичен:** оракул функциональной позиции по запиненным UCD-свойствам (lb=SA для ZWSP; InCB=Linker × Consonant для ZWJ; JT+after-R для ZWNJ без изменений). A — только strict-both с прозрачностью Mn/Me/Cf/Zs+Common P/N/So, как производная проекция; A-any/A-dom/loose — запрещены (похоронены замером, стражи в V5).
2. **V2 = (ii)∧(iv):** понижение до witness-агрегата B6 строго вне host/машинных полей; механическая статистика с разделёнными счётчиками + подпись штатности; никогда построчно; ярлык LIMIT при N≥16 (наследие); дедупликация witness (наследие).
3. **Эмодзи-исключение вне дельты:** запрет применения глубины к существующему эмодзи-контролю (ячейки не двигаются — замер [ЗАМЕР-RRT-SNI-8]).
4. **Именование остатка:** REGRESSION_CARD_ZWSP_NATIVE с fail-visible KNOWN_BLINDNESS-пином на 1-носительных ячейках; двойная честность в пользовательских формулировках; запрещённые формулировки пополнены (§2.V6).
5. **Ноль числовых порогов** в дельте (конструктивно соблюдено — зафиксировать в SNI-CONST-PIN); «письменности защищены» и родственные формулировки запрещены навсегда.

### Блокеры (до AUTHOR_DECISION / до кода)

- **B1 (авторский):** выбор размещения дельты (карточный слой vs гашение в релейшн BOUNDARY_DISRUPTOR — замеры инвариантны) + решение по кандидату SNI-FP-KHMER-COENG-ZWJ carve-out (1 элемент, отдельное решение, требует SNI-M4).
- **B2 (наследие B4):** обязательный прогон delta-census на ЖИВОМ карточном ядре до авторизации (ожидания группы 1 — реконструкция по §1); живой код ревьюерам недоступен.
- **B3 (авторский):** авторизация 2 новых строк пина UCD 16.0.0 (LineBreak.txt e97e4259…, DerivedCoreProperties.txt 39d35161…) + генератор SNI-ORACLE-GEN (прецедент ZW-CENSUS-GEN).

- **B5 (процессный):** запрет наивного (ii) — глубина применяется только к новым классам (страж SNI-EMOJI-CONTROL-FROZEN).
- **B6 (полевой):** замеры SNI-M1 (доля ЮВА-трафика, частоты C1–C6) и SNI-M4 (COENG+ZWJ в живом корпусе) — до снятия статуса UNMEASURED_SA_TRAFFIC.
