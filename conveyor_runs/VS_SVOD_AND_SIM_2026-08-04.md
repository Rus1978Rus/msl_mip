SIM-E (P7 GPT — ЖЁСТКИЙ ACCEPTANCE-КРИТЕРИЙ). «Если 13-байтовая нагрузка §1 состоит только из
  санкционированных пар и остаётся pass — дизайн не завершён». ЗАМЕР по реальным таблицам:
  нагрузка 13 байт -> санкционировано 0 из 13; нагрузка 200 байт -> 0 из 200.
  **Критерий ПРОЙДЕН**: точная валидация ловит измеренные нагрузки целиком, first-cut на одной
  таблице не разваливается.
SIM-F (ПЕРЕПОДПИСЬ МОЕГО ЖЕ §1 — честность). Я назвал «CJK+VS1» зазором. ЗАМЕР: U+349E+FE00
  ЗАРЕГИСТРИРОВАНА (молчать на ней ПРАВИЛЬНО), U+845B+FE00 (моя тестовая база) НЕ зарегистрирована.
  => Формулировка §1 неточна: дефект не «CJK+VS1 молчит», а **«молчание на НЕЗАРЕГИСТРИРОВАННОЙ
  паре»**. Переподписать в решении (паритет с переподписью paypal．com в W7).
SIM-G (ПОДТВЕРЖДЕНИЕ + УСИЛЕНИЕ ЗАЯВЛЕНИЯ ПАНЕЛИ). Панель: «IVD использует только E0100–E011F,
  32 селектора из 240; FE00–FE0F в IVD не бывает». ЗАМЕР: ПОДТВЕРЖДЕНО ТОЧНО (32 селектора,
  диапазон U+E0100..U+E011F, FE00–FE0F отсутствуют).
  **МОЁ СЛЕДСТВИЕ, которого нет ни у одной леги и ни у панели:** санкционированный IVD-селектор
  кодирует ТОЛЬКО байты 16..47. Это значит:
    - байты >= 48 НИКОГДА не могут ехать на санкционированной IVD-паре;
    - из печатных ASCII достижимы лишь пробел и ` !"#$%&'()*+,-./ `;
    - **ЛЮБАЯ буква или цифра в нагрузке структурно НЕсанкционируема** (A=65, a=97, '0'=48 — все >= 48).
  => Текстовая нагрузка ловится точной валидацией ПРАКТИЧЕСКИ ВСЕГДА, а не вероятностно. Это
  усиливает критерий (а) сильнее, чем оценка панели p ~= 1 - 0.011^13.
SIM-H (M2 — ЗАКРЫТ БЛОКЕР ПАНЕЛИ B5). Панели не дали gate_w4_vs_axis.py. ЦЕНЗ ЖИВОГО ГЕЙТА:

  пойдёт delta-манифест; объём сдвига обозрим (главный дельта-блок панели — 5 записей).
SIM-I (АРИФМЕТИКА ОСТАТКА — проверка P4 GPT против «~1-2 бита» Gemini/Qwen). ЗАМЕР по реальным
  таблицам: баз с >=1 селектором 16016; распределение k: k=1 -> 8905 баз (58%), k=2 -> 2405,
  k=3 -> 2742, ... **max k=32 (U+9089)**; медиана k=1, среднее 1.97.
  Остаточная ёмкость log2(k+1): медиана 1.00 бит/база, среднее 1.44, **max 5.04**.
  ПРАКТИЧЕСКИ: 100 знаков обычного прикрытия несут ~100 бит ~= **12 байт**; атакующий, подобравший
  100 самых «богатых» баз, — ~338 бит ~= **42 байта**.
  => Формула GPT (Sigma log2(k_i+1)) ТОЧНА; оценки «~1-2 бита» верны как медиана, но ЗАНИЖАЮТ хвост.
  Числа панели (0.94-1.4 avg, max 5.00) сходятся с моими в пределах метода подсчёта. Остаток РЕАЛЕН.
