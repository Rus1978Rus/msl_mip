§1. ФАКТ (не на ревью — данные в теле)
============================================================

  взаимозаменяемости X↔Y между знаками поднадзорного класса. НЕ свойство, НЕ
  отдельный ПЕРЕЧЕНЬ знаков. Это НЕ пересматривается.
- НАБОР ФИКСИРОВАН: всё происходит ВНУТРИ поднадзорного класса = 138 (Cf∧DI, UCD
  16.0.0; D-NEIGHBORS-BORDER-138). Форма НЕ добавляет и НЕ убирает знаки — только
  СТРУКТУРИРУЕТ связи внутри 138. Разбивка класса (справочно): PURE 23 + DIRECTIONAL
  12 + TAG 97 + DEPRECATED 6 = 138.
- ОТКРЫТО: КАК описывать это отношение (форма). Прошлый круг дал расщепление 1/2/1
  (пары-по-фильтру / кластеры-по-вектору / растворение в SIGN_RELATIONS) — консенсуса
  нет, потому этот круг.
- BY_SPEC-РАЗБРОС 5·9·12·16·22·33·~390 (медиана 16): «взаимозаменяемость для
  наивного фильтра» БЕЗ фиксации фильтра неопределённа. Прямой довод, что любая
  форма, зависящая от «фильтра вообще», нестабильна, пока фильтр не задан.

--- A. ПОПАРНЫЕ / ЯВНЫЕ РЁБРА ---
FORM-01. ПОЛНАЯ МАТРИЦА N×N (138×138, булево на каждую пару).
  ОБХОД: атака берёт пару, помеченную «не взаимозаменяемы» ошибочно. ЛОМАЕТСЯ:
  19044 ячейки, большинство пусты; поддержка вручную нереальна. СЧИТАЕМА: да, но
  требует правила заполнения (какой признак ставит 1) → сводится к другой форме.
  ФИЛЬТР: да, если ячейка = «неразличимы для F».
FORM-02. РАЗРЕЖЕННЫЙ ГРАФ / СПИСОК РЁБЕР (только взаимозаменяемые пары, ненаправл.).
  ОБХОД: знак вне графа (новый/не внесён) не виден. ЛОМАЕТСЯ: полнота — ребро
  появляется только если кто-то его внёс. СЧИТАЕМА: да, если ребро генерится
  правилом; иначе курируется. ФИЛЬТР: зависит от правила ребра.
FORM-03. НАПРАВЛЕННЫЙ ГРАФ (X→Y: X может ВСТАТЬ ВМЕСТО Y, асимметрия).
  ОБОСНОВАНИЕ: «X проходит там, где ждут Y» не всегда симметрично. ОБХОД: как F02.
  ЛОМАЕТСЯ: удвоение рёбер, сложнее читать. СЧИТАЕМА: да. ФИЛЬТР: да.
FORM-04. ВЗВЕШЕННЫЙ ГРАФ (рёбра несут вес: тяжесть/вероятность подмены).
  ОБХОД: низковесное ребро проигнорируют. ЛОМАЕТСЯ: откуда веса (эмпирика?
  экспертно?) — источник спорен. СЧИТАЕМА: структура да, веса — нет из UCD.
  ФИЛЬТР: вес может = «сколько фильтров не различают».
FORM-05. ПО-ЗНАКОВЫЙ ПРОФИЛЬ (для каждого из 138 — список «на что я подменяем»,
  поле карточки/реестра). ОБХОД: знак без профиля молчит. ЛОМАЕТСЯ: 138 профилей
  держать в синхроне. СЧИТАЕМА: да (эквивалент adjacency-list графа F02). ФИЛЬТР:
  зависит от правила.

--- B. ГРУППОВЫЕ / РАЗБИЕНИЯ ---
FORM-06. РАЗБИЕНИЕ ПО МЕХАНИЗМУ (классы эквивалентности по функции: разрыв / склейка /
  подавление / переворот направления / no-break / …), непересекающиеся, БЕЗ фильтра.
  ОБХОД: знак с двойной функцией не влезает в один класс. ЛОМАЕТСЯ: «механизм» надо
  определить формально. СЧИТАЕМА: да, если механизм = UCD-свойство. ФИЛЬТР: нет.
FORM-07. РАЗБИЕНИЕ ПО UCD-СВОЙСТВУ (готовые 4 класса: PURE 23 / DIRECTIONAL 12 /
  TAG 97 / DEPRECATED 6). ОБХОД: подмена МЕЖДУ классами (ZWSP↔RLO) не описана — а
  наивный zero-width-фильтр их путает. ЛОМАЕТСЯ: границы классов = границы UCD, не
  границы атак. СЧИТАЕМА: ДА, уже посчитано, из unicodedata. ФИЛЬТР: НЕТ (инвариант
  свойства). УСТОЙЧИВА: высоко (только смена версии Unicode двигает числа).
FORM-08. ПЕРЕСЕКАЮЩИЕСЯ КЛАСТЕРЫ (знак в НЕСКОЛЬКИХ группах подмены сразу; не
  разбиение). ОБХОД: как F06. ЛОМАЕТСЯ: пересечения усложняют «к какой группе».
  СЧИТАЕМА: да, если членство = набор предикатов. ФИЛЬТР: зависит.
FORM-09. РАЗБИЕНИЕ ПО ВЕКТОРУ АТАКИ / ЦЕЛИ (что ЛОМАЮТ: разрыв домена / инъекция в
  код / спуф идентификатора / LLM-тег-инъекция / bidi-спуф), а НЕ по механизму.
  ОБХОД: новый вектор атаки не покрыт. ЛОМАЕТСЯ: «вектор» = внешнее знание об
  атаках, не свойство знака → неполно по определению. СЧИТАЕМА: частично (нужен
  курируемый список векторов). ФИЛЬТР: нет, но зависит от корпуса атак.

--- C. ПАРАМЕТРИЗОВАННЫЕ ФИЛЬТРОМ ---
FORM-10. ПАРЫ ПОД ОДИН ЭТАЛОННЫЙ ФИЛЬТР F (substitution_F(X,Y) = X,Y неразличимы
  для зафиксированного F). ОБХОД: знак вне модели F ломает следующий слой. ЛОМАЕТСЯ:
  ВЫБОР F — сам развилка (разброс 5–390). СЧИТАЕМА: да, ПОСЛЕ выбора F. ФИЛЬТР: ДА
  (по определению). УСТОЙЧИВА: низко (сменил F → сменилась матрица).
FORM-11. СЕМЕЙСТВО R(F) НАД НАБОРОМ ФИЛЬТРОВ (каждый F → своё разбиение/граф).
  ОБХОД: атака между моделями фильтров. ЛОМАЕТСЯ: комбинаторный рост (N фильтров ×
  пары). СЧИТАЕМА: да, но дорого. ФИЛЬТР: ДА (весь смысл). Честнее F10 (не прячет
  зависимость), но тяжелее.

--- D. УПОРЯДОЧЕННЫЕ / ИЕРАРХИИ ---
FORM-12. ИЕРАРХИЯ ПО СИЛЕ ПОДМЕНЫ (всегда-подменяем ⊃ подменяем-после-нормализации
  ⊃ подменяем-только-под-конкретным-фильтром). Порядок по РОБАСТНОСТИ подмены.
  ОБХОД: атака на нижнем уровне, где «только под фильтром». ЛОМАЕТСЯ: уровни надо
  формально задать. СЧИТАЕМА: частично. ФИЛЬТР: нижние уровни — да, верхний — нет.
FORM-13. СЛОИ ПО СТАДИИ ОБРАБОТКИ (подменяемость на стадии strip-invisibles / на
  стадии NFKC / на стадии regex). ОБХОД: стадия, не покрытая моделью. ЛОМАЕТСЯ: надо
  знать реальный конвейер жертвы (обычно неизвестен). СЧИТАЕМА: нет без модели
  конвейера. ФИЛЬТР: да (стадия = фильтр).

--- E. ВЫЧИСЛЯЕМЫЕ ПО ЗАПРОСУ ---
FORM-14. ГЕНЕРАТИВНЫЙ ПРЕДИКАТ is_substitutable(X, Y, op) — вычисляется в момент
  запроса из UCD + операции, НИЧЕГО не хранится. ОБХОД: если op неверно моделирует
  фильтр жертвы. ЛОМАЕТСЯ: «op» — тот же вопрос фильтра, только отложенный.
  СЧИТАЕМА: да, по запросу (числа фиксированного нет — оно функция op). ФИЛЬТР: да
  (через op). ПЛЮС: не хранит лишнюю структуру.

--- F. ЭМПИРИЧЕСКИЕ ---
FORM-15. КУРИРУЕМЫЙ КОРПУС АТАК (пары = замеченные в реальных атаках/CVE).
  ОБХОД: любая НОВАЯ атака вне корпуса. ЛОМАЕТСЯ: неполно ПО ОПРЕДЕЛЕНИЮ (только
  прошлые атаки). СЧИТАЕМА: да (счёт = размер корпуса), но не из UCD. ФИЛЬТР: нет,
  но зависит от источника атак. Ценность: приоритизация реального, не полнота.

--- G. ГИБРИД / МИНИМУМ / НЕТ ---
FORM-16. ДВУХУРОВНЕВЫЙ ГИБРИД: скелет — кластеры по UCD/механизму (F06/F07, без
  фильтра, устойчивый); детализация — пары/граф ВНУТРИ кластера под выбранный
  фильтр (F10). ОБХОД: как у слабейшего уровня. ЛОМАЕТСЯ: два слоя держать в
  синхроне. СЧИТАЕМА: скелет да сразу, детали — после выбора F. ФИЛЬТР: только
  нижний уровень. (Совмещает устойчивость и точность.)
FORM-17. РАСТВОРЕНИЕ В SIGN_RELATIONS (не заводить отдельную структуру; подменяемость
  = аспект рёбер карточки знака: BOUNDARY_DISRUPTOR/INVISIBLE_CLASS_COLLISION с
  target_kind). ОБХОД: знак без карточки → только witness, без описания подмены.
  ЛОМАЕТСЯ: требует карточку на каждый значимый знак (сейчас одна — ZWSP).
  СЧИТАЕМА: счёт = число знаков с активными рёбрами (сейчас 1). ФИЛЬТР: нет.
  НЕ растит сущность (переиспользует существующее).
FORM-18. WITNESS-ONLY / НЕ МОДЕЛИРОВАТЬ (сознательно НЕ описывать подмену отдельно;
  все 138 единообразны для witness, отношение остаётся неявным «по природе»).
  ОБХОД: не различаем опасные подмены от безобидных внутри класса. ЛОМАЕТСЯ: теряем
  всю гранулярность (зачем тогда «отношение»?). СЧИТАЕМА: тривиально (структуры
  нет). ФИЛЬТР: нет. НЕ растит сущность (её просто нет).
