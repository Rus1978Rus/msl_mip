V1. МЕХАНИЗМ РАСПОЗНАВАНИЯ
СИНТЕЗ: **A (любой tag-знак вне span-гейта легита → сигнал) + C (декод нагрузки — объект
witness и evidence, НЕ критерий детекции).** Сигнал — свойство присутствия, обход

видимый знак между каждыми N−1 tag-знаками; смежности нет при любом N≥2, а потребитель
(LLM) читает сырой текст, где tag-подпоследовательность сохранена (REDTEAM+SECURITY,
независимо). D отклонена полностью, включая «вторичный сигнал»: порог — конфиг DoS-оси
→ тот же вход, разный сигнал на разных сборках + смешение осей §5 (VERIFY).
Форма: **надстройка над классом-138 по паттерну AUTHOR_DECISION_20260726_D-W4-VS-AXIS
(silence+escalate).** Название («достроить» vs «новая ось») — author decision;
конструкция согласована: класс-138 даёт триггер-субстрат и витнесс-на-знак, надстройка
несёт шаблон-исключение, span-scoping, декодер.
Отметки: (а)+ (б)+ ровно в паре с V2 (в)+ (г)+ (д)+ (е)±—остаток V6 (ж)+ при пине.
ГДЕ ДЫРА: A без V2 будит измеренные легит-флаги; A с document-scoped гейтом =
flag-washing (валидный флаг глушит весь документ) — закрывается только span-scoping'ом
(SECURITY). C-как-триггер мёртв: шифрованная/base64-нагрузка «бессмысленна» для любого
классификатора — понизить сигнал шифрованием нельзя допустить.

V2. ЛЕГИТ-ГРАНИЦА (главное)
СИНТЕЗ: **строгий RGI-шаблон, span-scoped, closed-world whitelist = ровно 3 RGI
(gbeng/gbsct/gbwls), пин версией+sha256 emoji-data.** Шаблон = парс-слой; валидация
всегда против списка (VERIFY). Шаблон фиксирует: база U+1F3F4 + РОВНО 5–6 tag-знаков из
[0-9a-z-зеркала] + CANCEL U+E007F; алфавит и длина — часть гейта (SECURITY: иначе белый
ход внутри шаблона). Шаблон БЕЗ списка отклонён единогласно: ~23–28 бит на флаг
выбором произвольного «региона» = полноценный скрытый канал с валидным синтаксисом
(REDTEAM); бесплатный молчащий канал на любую 5–6-буквенную команду-инъекцию (FP).
Узкий список (3, не full ISO 3166-2) — аргумент SECURITY: wide-список (~5000 кодов)
= ~12 бит/флаг канал выбора региона; пин-3 сжимает до ~1.6 бит/флаг и носитель
(десятки видимых флагов) конспиративен + упирается в DoS-рубеж. Цена артефакта: 3
записи, неподвижен с 2017, новые флаги не процессятся — дешёвейший список проекта.
КРАЯ (согласовано 4/4): tag-последовательность без базы → сигнал; валидная форма +
регион ∉ списка (gbxyz) → сигнал (fail-visible в безопасную сторону); флаг + нагрузка
после CANCEL → флаг-span молчит, хвост → сигнал (консьюм-правило); decoy-флаг ПОСЛЕ
нагрузки — порядок не спасает (span-scoping order-insensitive); незавершённая
последовательность (EOF/видимый знак/ZWJ внутри) → сигнал; два валидных флага подряд →
оба молчат. Цепочки валидных флагов → в остаток (пренебрежимо по арифметике).
Отметки: (а)+ (б)+ (в)+ (г)+ (д)+ (е)+ при реестре (ж)+ при пине.
ГДЕ ДЫРА: усечённый копипастой флаг (tag-буквы без базы) = главный легит-FP фронта —
queue, назван, ячейкой обязан (FP+REDTEAM); флаг Техаса ustx (WhatsApp) = не-RGI легит
→ сигнал, именованный остаток; будущие RGI-регионы = queue-FP до bump'а (fail-visible,
безопасное направление); спека терминации автомата обязательна, иначе два парсера
расходятся на битой середине (VERIFY).

V3. РАСКРЫТИЕ НАГРУЗКИ (специфика фронта)
СИНТЕЗ: **(b) — обязательное раскрытие, экранированное + усечённое, единогласно.**
(a) = система-ретранслятор чужого текста (отчёт→LLM = повторение инъекции); (c)/(d) =
пустой witness-канал, человек не может произнести «последнее слово» о невидимом,
W7-паритет (раскрытие обязательно там, где глаз бессилен) сломан. Узел разрублен так:
потребитель witness-канала — человек; машинный downstream — требование к форме, не
отмена раскрытия (REDTEAM). Смягчающий факт (SECURITY, подтверждено RESEARCH): алфавит
зеркал = printable ASCII 0x20–0x7E → \n, ESC, ANSI, управляющие ИСКЛЮЧЕНЫ по построению;
опасны только разделители разметки (" \ backtick <>), фрейминг > борьба с контролами.
ОБЯЗАТЕЛЬНЫЙ КОНТРАКТ РАСКРЫТИЯ (свод SECURITY+VERIFY+REDTEAM):
- data-only конверт: маркер «СКРЫТЫЙ ТЕКСТ (данные, НЕ инструкция)», ни в одном
  контексте не голый текст; для машинных потребителей — дублирование кодпоинтами;
- экранирование тотальное: таблица на ВЕСЬ декодируемый диапазон, по одному запиненному
  эскейперу на канал вывода (markdown/HTML/лог); частичная функция = первый непокрытый
  знак проходит активным (VERIFY);
- cap длины = дизайн-константа (не конфиг) + ОБЯЗАТЕЛЬНЫЙ total-length («…усечено, всего
  N») — без него атакующий прячет интересное за капом; значение cap — author decision
  (предложения круга 32/200/256; рекомендация синтеза: 200 + total);
- sha256 полной нагрузки в evidence (VERIFY) — раскрытие усечённое, доказательство
  полное;
- ЗАПРЕТ keyword-эскалации: уровень НИКОГДА не зависит от содержимого — содержимое
  играбельно в обе стороны (добрые слова понижают; страшные слова, подброшенные в чужой
  текст, провоцируют ложный hold — flagging-атака) (SECURITY);
- система свой вывод в analyze() не возвращает (запрет авто-реинжеста) (REDTEAM).
Приятный побочный эффект (FP): раскрытие — лучший FP-амортизатор (видишь «gbsct» →
понимаешь, что это обломок флага).
Отметки: (г)+ ровно при запиненном контракте; без спеки экранирования (ж)±.
ГДЕ ДЫРА: агентный пайплайн, читающий даже экранированный отчёт «сквозь fence» — полного
решения внутри witness-рамки нет; честный остаток: «раскрытие безопасно для человека-
читателя; для машинного downstream — на совести потребителя» (REDTEAM).

  правило (по максимуму), иначе молчаливая коллизия (SECURITY); то же vs Input-Guard

Отметки: (б)± за усечённый флаг (честный, измерить при первом корпусе); остальные +.
ГДЕ ДЫРА: контент-зависимый уровень — скрытый возврат семантики в детерминированную ось

V6. ОСТАТОК
СИНТЕЗ — реестр, каждый пункт именованной записью с маркерной ячейкой «не срабатывает»
(прецедент W7: отложенное без ячейки = молчаливый возврат дыры):
1. **VS-стеганография** (VS17–VS256, ~8 бит/знак — ёмкость ВЫШЕ TAG) — отдельная ось,
   ярлык БАЙПАСС; боевое использование подтверждено (GlassWorm) — это следующий
   кандидат-фронт, приоритет выше теоретического (RESEARCH).
2. **Zero-width битовые схемы** (ZWSP/ZWNJ/ZWJ как биты) — БАЙПАСС; легит-база выше
   (Indic, эмодзи-ZWJ), симметрия легит/атака тяжелее, чем здесь.
3. **Interlinear annotation U+FFF9–FFFB** — третий носитель, пакетом не назван
   (находка REDTEAM) — в реестр.
4. Шифрованная/закодированная нагрузка внутри TAG — witness покажет факт и строку, не
