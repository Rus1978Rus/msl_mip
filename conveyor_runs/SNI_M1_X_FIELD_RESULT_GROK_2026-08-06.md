# SNI_M1_X_FIELD_RESULT — лега Grok (X/Twitter) + разбор координатора

ПОЛУЧЕНО: 2026-08-06. Дисциплина отчёта соблюдена: числа с размерами выборок, раздел
UNMEASURED, анти-ретрансляция, честное смещение выборки.

## Итог леги (кратко)
Выборка ~35-40 постов (не 200): кхмерский слой X тонок (ad reach ~718k, ~4% населения;
доминирует Facebook). ГЛАВНЫЙ РЕЗУЛЬТАТ — ОТРИЦАТЕЛЬНЫЙ И МЕТОДОЛОГИЧЕСКИЙ:
**выдача/поиск X нормализует или срезает U+200B** → сырые носители в возвращённом тексте
не видны → M1-M3 ЭТИМ ИНСТРУМЕНТОМ НЕИЗМЕРИМЫ. «0» Grok по редким носителям (M4) —
«0 в выдаче», не «0 в природе». Ф1 (~13%) ни подтверждён, ни опровергнут.
Побочно: невидимые «спейсеры»-декор в display-name/bio (зона userinfo/display-фронта);
хэштеги у кхмерских аккаунтов преимущественно латиницей; NIDA-факт (ZWSP на пробеле)
подтверждён литературой ещё раз.

## Разбор координатора

1. СТАТУС УТВЕРЖДЕНИЯ «X СРЕЗАЕТ ZWSP»: нами напрямую НЕ проверяемо (нет доступа к X),
   помечено UNVERIFIED-BY-US. Косвенно согласуется с нашими замерами ДРУГИХ платформ:
   Telegram-превью СОХРАНЯЕТ ZWSP (21 шт. в нашей выборке), Википедия сохраняет (912).
   Платформы трансформируют носители ПО-РАЗНОМУ — это измеренный факт минимум для двух.

2. НОВЫЙ ФАКТ-КЛАСС ДЛЯ СЕМЬИ «СКРЫТЫЕ КАНАЛЫ»: **ТРАНСПОРТНАЯ НОРМАЛИЗАЦИЯ**.
   Скрытый канал на носителях обязан ПЕРЕЖИТЬ конвейер платформы; нормализующая
   платформа (если X таков) убивает ZWSP-канал в транзите — и ровно так же калечит
   ЛЕГИТИМНЫЕ кхмерские границы слов (платформа вредит письменности, не только атаке).
   Следствие для модели угроз: канал выбирает НЕнормализующие транспорты; наша система
   стоит ПОСЛЕ транспорта и видит только то, что он пропустил. Записано как наблюдение,
   НЕ как правило (никакого «пришло из X ⇒ подозрительно»).

3. **SNI-M4 ЗАКРЫТ ЗАМЕРОМ КООРДИНАТОРА** (Grok дал слабый ноль, у нас корпуса с
   сохранёнными кодпоинтами): COENG+ZWJ = **0 на 15 945 COENG** (184 694 кхмерских
   знака: вики-статьи 155k+49k+summary, Tatoeba 2463 разговорных предложения, Telegram).
   COENG+ZWNJ = 0. Конструкция TUS §16.4 в живом тексте ПРАКТИЧЕСКИ ОТСУТСТВУЕТ.
   ⇒ РЕКОМЕНДАЦИЯ ПО D-SNI-5: carve-out НЕ НУЖЕН — остаток SNI-FP-KHMER-COENG-ZWJ
   стоит ~ничего в поле; оставить именованным остатком навсегда (queue+нота на
   экзотику — корректное поведение свидетеля). Формальное закрытие — за автором.

4. SNI-M1 ПО КАНАЛАМ: X — инструментально неизмерим (закрыто с причиной);
   Telegram — измерен (наш замер 4); Tatoeba — измерен; Facebook — недоступен наружу
   (главный носитель аудитории; честно висит в UNMEASURED). Ф1 «13% разговорных с
   ZWSP» подтверждён только на Tatoeba; вторая платформа для сверки — открытый пункт.

5. Метод для будущих полевых замеров (из леги, поддерживаю): собирать только каналами,
   сохраняющими кодпоинты as-is (наш curl+файл путь; ручной copy с проверкой ord());
   текст из search-API соцсетей для замеров носителей НЕПРИГОДЕН.
