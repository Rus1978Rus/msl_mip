## НАХОДКА 1 (СЕРЬЁЗНАЯ): карточка ZWSP наказывает письменности без пробелов
ИЗМЕРЕНО: любой ZWSP даёт `semantic_action = queue_for_review` через релейшн
  BOUNDARY_DISRUPTOR (risk MEDIUM, context BYTE_EXACT_TOKEN). Проверено и на латинице
  (`word<ZWSP>word` → queue), то есть это ДАВНЕЕ поведение карточного слоя, а не регрессия новых осей.
ПОЧЕМУ ЭТО ВАЖНО: в кхмерском, тайском, лаосском и мьянманском **ZWSP — штатный разделитель слов**;
  пробел там не используется. Для этих письменностей ZWSP — то же, что для нас пробел.
ЗАМЕР (текст из 10/20/40 слов, разделённых ZWSP):
  кхмерский   → queue во всех случаях (носителей 11/23/43)
  тайский     → queue (11/20/41)
  лаосский    → queue (11/21/41)
  мьянманский → queue (11/21/41)
  Моя новая ось при этом МОЛЧИТ корректно (`contributed=False`, нефункциональных 0) — правило
  ZWSP=PLAUSIBLE_FUNCTIONAL работает. Эскалирует карточный/релейшн-слой.
МАСШТАБ: вся зона scriptio continua Юго-Восточной Азии. Внешний факт (RESEARCH панели, L2/08-344):
  в кхмерской национальной раскладке ZWSP стоит на Shift+Space и составляет ~16 нажатий из 100.
  Т.е. нормальный кхмерский текст обречён на постоянный queue.
СТАТУС: НЕ регрессия — дефект существовал до всех пяти новых фронтов. Ни одна батарея его не
  ловила, потому что ни в одной не было ни одного текста этих письменностей.

## НАХОДКА 2: карточка ZWJ знает про эмодзи, но не знает про индийские конъюнкты
ИЗМЕРЕНО:
  эмодзи + ZWJ + эмодзи        → sem = **pass**   (исключение существует)
  деванагари + ZWJ + деванагари → sem = **queue**  (исключения нет)
  малаялам + ZWJ               → queue
  бенгали/тамильский/гуджарати с ZWNJ → pass (ZWNJ БЕЗ карточки, поэтому не задет)
ПОЧЕМУ ЭТО ВАЖНО: в деванагари и малаялам ZWJ — обязательная орфография (форма конъюнкта), ровно
  как в эмодзи-последовательности. Кто-то уже осознал этот класс проблемы и сделал carve-out —
  но ТОЛЬКО для эмодзи. Индийские письменности остались снаружи.
АСИММЕТРИЯ ЗАМЕТНА ВНУТРИ ОДНОЙ КАРТОЧКИ: одна и та же функция знака признана легитимной для
  эмодзи и подозрительной для хинди.
СТАТУС: НЕ регрессия, давнее.

   случай.
4. Карточный слой — самый защищённый (батареи ZWSP 21/21, ZWJ/BOM живые), поэтому правка обеих
   находок требует ОТДЕЛЬНОГО author decision + delta-манифеста. В этом аудите код НЕ трогается.

РЕКОМЕНДАЦИЯ АВТОРУ: обе находки — материал для отдельного круга (или одного объединённого),
  потому что вопрос у них общий: **какие ещё письменности используют невидимые знаки штатно, и
  почему карточный слой знает про эмодзи, но не про них.** Предлагаемое имя фронта:
