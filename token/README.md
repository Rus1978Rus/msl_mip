# MSL Coin — ERC-20 токен

Полноценная криптовалюта (токен стандарта ERC-20) на базе аудированных
контрактов [OpenZeppelin](https://www.openzeppelin.com/contracts). Проект
собран на [Hardhat](https://hardhat.org).

## Возможности контракта

| Функция | Описание |
|---|---|
| ERC-20 | Стандартный токен: переводы, allowance, 18 знаков после запятой |
| Cap (потолок эмиссии) | Жёсткий максимум общего предложения, задаётся при деплое и не меняется |
| Mint | Владелец может довыпускать токены, но никогда выше потолка |
| Burn | Любой держатель может сжечь свои токены |
| Permit (ERC-2612) | Approve по подписи — держателю не нужен ETH на газ для approve |
| Ownable | Владельца можно сменить или отказаться от владения (`renounceOwnership`) |

Имя, тикер, стартовая эмиссия, потолок и владелец задаются **аргументами
конструктора при деплое** — в коде ничего не захардкожено.

## Структура

```
token/
  contracts/MSLToken.sol    Контракт токена
  test/MSLToken.test.js     Тесты (13 шт.)
  scripts/deploy.js         Скрипт деплоя
  hardhat.config.js         Конфигурация (сети, компилятор)
```

## Быстрый старт

Требуется Node.js 18+.

```bash
cd token
npm install
npm test          # компиляция + 13 тестов в локальной EVM
```

Компилятор Solidity берётся из npm-пакета `solc` (см. `hardhat.config.js`),
поэтому сборка работает даже без доступа к binaries.soliditylang.org.

## Деплой в тестовую сеть (Sepolia)

1. Создайте кошелёк для деплоя (например, MetaMask) и получите тестовый ETH
   из любого Sepolia-фаусета.
2. Получите RPC-URL (бесплатно у [Alchemy](https://alchemy.com) или
   [Infura](https://infura.io)) и API-ключ [Etherscan](https://etherscan.io/apis)
   для верификации.
3. Задайте переменные окружения (не коммитьте их в git!):

```bash
export SEPOLIA_RPC_URL="https://eth-sepolia.g.alchemy.com/v2/<ключ>"
export PRIVATE_KEY="<приватный ключ кошелька деплоя>"
export ETHERSCAN_API_KEY="<ключ etherscan>"

# Параметры токена (необязательно — есть значения по умолчанию)
export TOKEN_NAME="MSL Coin"
export TOKEN_SYMBOL="MSL"
export TOKEN_INITIAL_SUPPLY="1000000"   # целых токенов при старте
export TOKEN_CAP="10000000"             # потолок эмиссии
# export TOKEN_OWNER="0x..."            # владелец, по умолчанию — деплоер
```

4. Деплой и верификация:

```bash
npm run deploy:sepolia
# скрипт напечатает адрес контракта и готовую команду npx hardhat verify
```

После верификации токен виден на sepolia.etherscan.io, его можно добавить
в MetaMask по адресу контракта и переводить между кошельками.

## Деплой в основную сеть (mainnet)

То же самое с `MAINNET_RPC_URL` и `npm run deploy:mainnet`. Перед этим:

- **Проверьте параметры дважды** — cap и имя после деплоя изменить нельзя
  (только деплоить новый контракт).
- Деплой стоит реального ETH (газ).
- Храните приватный ключ владельца максимально надёжно (аппаратный кошелёк,
  мультисиг типа Safe). Владелец может минтить токены — компрометация ключа
  означает компрометацию эмиссии.
- Если довыпуск не нужен вовсе — после деплоя вызовите `renounceOwnership()`,
  и эмиссия станет неизменяемой навсегда.

## Важные оговорки

- Контракт собран из стандартных аудированных модулей OpenZeppelin, но сам
  проект отдельному аудиту не подвергался.
- Выпуск токена сам по себе легален, однако публичная продажа или привлечение
  средств может подпадать под регулирование ценных бумаг в вашей юрисдикции —
  проконсультируйтесь с юристом до запуска.
